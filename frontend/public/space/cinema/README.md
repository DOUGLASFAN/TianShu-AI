# 4K 星系穿行

- 作品：[Flying Through Galaxies / NASA SVS 14950](https://svs.gsfc.nasa.gov/14950/)。
- 文件：`nasa-galaxies-4k.mp4`，原版 **3840×2160**，148,685,673 字节，下载后未重新编码或改写。
- 署名：**NASA's Goddard Space Flight Center/Conceptual Image Lab**。
- 制片：Scott Wiessinger (eMITS)；动画：Adriana Manrique Gutierrez (eMITS)；艺术指导：Walt Feimer (eMITS)。
- 海报：同一作品页面提供的 3840×2160 原始静帧。
- `manifest.json` 包含原始来源、哈希、文件大小及 MP4 轨道检查结果；原文件只有视频轨，没有音频轨。

这是专业制作的艺术概念动画，展示穿过星系组成的宇宙网络；不是实时卫星数据，也不是可自由操纵的实时三维场景。使用浏览器原生播放器，支持暂停、跳转和全屏。关闭电影后恢复原卫星三维视角。

使用依据：[NASA SVS 使用说明](https://svs.gsfc.nasa.gov/help/)和[NASA 媒体使用指南](https://www.nasa.gov/nasa-brand-center/images-and-media/)。保留原始作品署名，不使用 NASA 标志或暗示其背书。
