# 星枢地球贴图

作者与提供方：Solar System Scope / INOVE。来源：[Solar Textures](https://www.solarsystemscope.com/textures/)。

许可：[Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/)。项目界面保留提供方与许可署名，下载原件未作图像修改。

包含 `8k_earth_daymap.jpg`、`8k_earth_nightmap.jpg`、`8k_earth_clouds.jpg`，本项目分别命名为 `day-8k.jpg`、`night-8k.jpg`、`clouds-8k.jpg`。供应方说明这些贴图基于 NASA 影像等数据制作并调整了色彩；它们是历史合成可视化素材，不是实时影像、实时云图或定量夜光测量产品。网页未给出全部合成数据的确切年份，本项目不编造年份。

`day-preview.webp`、`night-preview.webp` 和 `clouds-preview.webp` 分别从对应原件缩小至 2048×1024、2048×1024 和 1024×512 后以 WebP 编码。预览文件沿用原作者署名和 CC BY 4.0 许可。探索页先用预览，随后逐层加载 8K 原件。

下载日期、原始地址、文件大小与 SHA-256 见 `manifest.json`。这些高分辨率资源在准备步骤复制到前端本地公开目录，浏览器运行时无需访问外部瓦片服务。地表范围为全球等距圆柱投影，球体采用 Cesium WGS84 椭球；光照与昼夜渐变由场景时间和太阳方向计算。
