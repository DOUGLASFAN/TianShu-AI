# 卫星预览模型集

2026-11-15。全部原件来自 NASA 官方 3D Resources 仓库，下载后核对 Git blob SHA 和本地 SHA-256，来源与作者见各目录 `manifest.json`。原件未修改，渲染侧调整光照、曝光和摆放角度。

| 目录 | 页面选项 | 原模型 | 贴图数量 |
| --- | --- | --- | --- |
| cygnss | 双翼卫星（默认） | CYGNSS | 1 |
| aqua | 对地观测 | Aqua (B) | 4 |
| tdrs | 通信中继 | TDRS (B) | 4 |
| cubesat | 立方星 | CubeSat - 1 RU Generic | 0，使用材质颜色 |
| generic-satellite | 气象卫星 | GOES | 0，使用材质颜色 |

遵守 [NASA 媒体使用指引](https://www.nasa.gov/nasa-brand-center/images-and-media/)，保留 NASA 和已知作者署名，不暗示 NASA 为项目背书；这些文件不另行标记为 CC 或 MIT。图像与缓冲均包含在 GLB 内，Draco 解码器和模型从项目本地加载，不依赖运行时外站请求。

这些选项是供用户切换的通用外形示意，选择某款预览不修改所选卫星的轨道数据，也不代表所有对象实际具有该结构或姿态。来源说明放在预览的“来源”展开项内。

光照优化：曝光从 1.25 降至 0.85，减少环境与方向补光，降低高光冲淡颜色的程度；保留素材自身颜色，不将所有卫星强制涂成蓝色或金色。CYGNSS 展示太阳能板正面，Aqua 调整摆放以适应横向区域。部分模型原有紫色或灰白材质是素材自身设计，不是缺失贴图。

模型默认缓慢自转，支持暂停、拖动、缩放、方向键和重置。减少动态效果开启时禁用自转；停止后不持续重绘，返回可见标签页时可继续用户开启的自转。切换和卸载释放解码器、几何、材质与 WebGL 上下文。

验证：[浏览器记录](../../docs/evidence/models-gallery-2026-11-15.json)、[双翼预览](../../docs/evidence/model-cygnss-2026-11-15.png)、[Aqua 预览](../../docs/evidence/model-aqua-2026-11-15.png)。已核对五款本地加载、切换、自转启停、静止渲染和资源释放，原型模型选择不等于新增后续业务阶段。
