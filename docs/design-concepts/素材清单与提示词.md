## 2. 登录背景接入建议

- CSS 背景或装饰性 img，装饰图 alt 为空；文字为独立 HTML。
- 原图优先完整留存，实现阶段按需求导出 WebP/AVIF 和合适尺寸；尚未完成优化格式导出。
- 默认背景定位 left center，按 16:9 设计；小屏减少图像存在感，通过不透明表单面保证可读性。
- 图片加载失败仍有纯深色底；静态图片不自动缩放漂移。
- 实测右侧表单、200% 缩放与 1440×900 等尺寸，不能认为生成后即通过界面验收。

## 3. 观测规划参考图的必要校正

- “亮度良好”无准确视星等依据，不进入产品；使用“卫星受光”。
- “可观测”不能替代几何过境或目视条件分类，使用明确标签。
- 经历时间、最大仰角、编号、受光与轨迹使用算法结果；图中日期均为示意。
- 北京观测站选点、地球昼夜与目视窗口必须由相同时间和数据驱动，静态图片不能验证一致性。
- 控件与图表均为可访问组件；不将截图裁成按钮、表格或曲线使用。
