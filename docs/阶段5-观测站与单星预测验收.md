# 阶段 5：观测站与单星预测

交付日期：2026-11-15。范围为 S05-01～S05-08；分组预测、动画回放、保存计划和提醒继续属于后续阶段。

## 使用入口

启动项目后，打开 [观测规划](http://127.0.0.1:5174/observations)。也可以在探索页选择卫星，点击“预测过境”，直接带入目标。

1. 新建观测站，填写 WGS84 经纬度和海拔，或在弹窗内点击地球选点。第一次创建自动成为默认站；支持编辑、切换默认和删除。
2. 选择卫星，设置开始时间、24 小时／3 天／7 天、0°～90°最低仰角。显示时区默认 UTC+8，可切换 UTC，切换保留同一时刻。
3. 提交后查看排队和计算进度，可取消。只有服务返回最终状态后才显示完成或已取消。离开页面不会自动取消，历史计算和任务 URL 可继续回查。
4. 结果支持时间／最高仰角排序、潜在目视筛选和分页。点击进入时间查看详情、仰角曲线、地面投影和目视子窗口。计算依据可以展开或导出。

输入条件改变时显示“条件已修改”，当前结果始终绑定原查询。删除或修改站点不会改写历史结果；已删除站点必须重新选择后才能复算。

## 数据与任务设计

- `observation_stations.is_default` 使用 PostgreSQL 部分唯一索引，默认站切换和删除在用户行锁下执行。删除默认站后选择最早保留站点；无站点时不虚构默认站。
- 新表 `predictions` 持久保存用户、状态、进度、条件依据、结果、错误代码及三个时间戳。站点采用不可变 JSON 快照，删除原站点仍能复核。迁移 `e520261115` 基于既有 `d420261112`，没有修改已应用的历史迁移。
- API 只负责验证、提交和读取；独立 worker 执行计算，持有 PostgreSQL 排他租约，避免重复消费。采集三个任务继续在独立线程执行。
- 状态为 `queued → running → completed / failed`；排队取消立即确认，执行取消先为 `cancelling`，工作线程检查后转 `cancelled`。最终写入与取消请求锁定同一行，完成后取消不覆盖已有结果。
- 中断执行的任务在下次取得工作租约后标记失败 `WORKER_INTERRUPTED`，不伪报完成；排队任务继续消费。每用户最多 3 个活跃任务、全局 32 个排队／执行任务；站点最多 50 个。
- 每次读取任务、事件、结果和取消均检查用户归属。结果接口分页和排序，不把全量曲线混入列表响应；详情单独读取曲线。

| 方法 | 地址 | 作用 |
| --- | --- | --- |
| GET / POST | `/api/stations` | 列表、创建 |
| GET / PATCH / DELETE | `/api/stations/{id}` | 读取、编辑／默认、删除 |
| GET / POST | `/api/predictions` | 私有历史分页、提交单星任务 |
| GET | `/api/predictions/{id}` | 状态、进度、依据、时效 |
| POST | `/api/predictions/{id}/cancel` | 取消并返回服务状态 |
| GET | `/api/predictions/{id}/results` | `page / size / sort=time或elevation / visual` |
| GET | `/api/predictions/{id}/events/{eventId}` | 事件、仰角／方位／距离／受光／地面坐标采样 |

## 计算规则与可信度

使用本地 Skyfield、SGP4、WGS84 和 DE421，无在线星历依赖。几何过境以仰角达到阈值为条件，计算进入、最高点、离开、方位、最大仰角和持续时间；查询边界截断及范围内持续高于阈值单独标识。方位以正北为 0°，顺时针增加。几何事件细化至 0.025 秒区间，局部细化最高点；这只是数值搜索容差，不代表实际观测准确到该时间。

潜在目视窗口同时要求仰角达到阈值、站点太阳高度低于 −6°、卫星受光。使用不超过 5 秒的间隔扫描全部过境，逐次保留多个子区间，变化边界细化至 0.25 秒；长过境分块计算并检查取消。小于采样间隔的短子窗口仍可能遗漏。

每份依据保存完整 OMM 根数、版本哈希、历元、来源、采集时间、站点快照、查询范围、仰角／太阳阈值、算法与采样容差；记录实际计算开始和完成时间。根数超过 72 小时或历元提前当前 10 分钟以上，提交需要明确确认。回查时提示根数陈旧／未来历元、版本更新、查询范围结束；预测区间远离根数历元也提示误差可能增加。

潜在目视不等于肉眼可见：未计算星等、天气、地形遮挡和大气折射。图像为历史合成静态贴图，地面投影为轨道计算，不是卫星实拍。独立参考使用相同 SGP4 理论并独立换算地固坐标和站心角度，不能充当真实观测或另一套独立轨道理论。

算法依据：[Skyfield 官方卫星文档](https://rhodesmill.org/skyfield/earth-satellites.html)、[Vallado 等 SGP4 修订论文](https://celestrak.org/publications/AIAA/2006-6753/)。阶段 1 的权威参考向量和局限继续保留。
