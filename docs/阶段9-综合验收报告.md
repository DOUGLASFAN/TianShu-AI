# 星枢 · 阶段 9 综合验收报告

验收日期 2026-11-21（北京时间）

## 功能、权限和交互

- Edge 走通登录、卫星搜索、关注回查、观测站编辑、历史整组回放、通知、空间环境、态势大屏和管理员数据源。通过本机 API 实际完成七天单星预测、保存过境计划并回放。103 项后端回归全部通过，各阶段使用独立测试数据库。[浏览器流程](./evidence/phase9-browser-2026-11-21.json) · [通知及天气](./evidence/phase9-notification-browser-2026-11-21.json) · [后端回归](./evidence/phase9-backend-regressions-2026-11-21.json)
- 验证匿名 401、普通用户访问后台 403、跨账户访问他人站点和计划返回 404。重复收藏和重复保存计划均只保留一条。完整重启项目、PostgreSQL 与 Redis 后，关注、站点、计划和计划回放均可回查。[接口与持久化记录](./evidence/phase9-api-2026-11-21.json) · [数据库与产物检查](./evidence/phase9-delivery-check-2026-11-21.json)
- 验证编辑弹窗键盘焦点、Escape 关闭和焦点回归，通知到达时保持回放滑块焦点，快速切换太阳系与月球时可中断未完成飞行。切换减少动态效果时保留已暂停的回放时刻。[交互专项](./evidence/phase9-interaction-2026-11-21.json) · [减少动态效果与回放](./evidence/explore-direct-entry-2026-11-21.json)
- 桌面 1920×1080、1440×900、1280×800 检查通过。在独立 Chromium 测试配置中实际设置标签页 200% 缩放，探索时间轴、观测站、采样管理和大屏主要控件仍可操作。大屏无页面滚动条，工作台允许纵向滚动。[桌面布局](./evidence/phase9-browser-2026-11-21.json) · [200% 浏览器缩放](./evidence/phase9-browser-zoom-2026-11-21.json)

## 性能实测

| 项目 | 实测结果 | 验收口径 |
| --- | --- | --- |
| 2,000 点和一条选中轨道 | 60.08 FPS | Edge、1920×1080、RTX 4060 Laptop GPU／Direct3D 11、预热后实际拖动相机约 8 秒 |
| 10,000 点总览 | 60.07 FPS | 同一条件，帧间隔 P95 16.8 ms，两档采样均无超过 50 ms 的帧间隔 |
| 热加载进入可操作地球 | 1.38 秒中位数 | 同一浏览器上下文内重新载入，各运行预热后测量，共三次 |
| 分页、详情、统计接口 | P95 分别为 5.52、3.63、6.39 ms | 本机连续 HTTP 请求，每项 100 次 |
| 单星七天预测 | 2.07 秒 | ISS，含入队等待与客户端轮询，后台计算 1.02 秒 |
| 500 星 24 小时预测 | 30.50 秒 | 真实目录批次，任务提交 125 ms，无计算失败对象 |
| 500 星七天预测 | 183.44 秒 | 真实目录批次，任务提交 77 ms，结果含 8,288 个事件 |

点位基准从同一次真实目录推算中分别取 2,000 和 10,000 个点，以固定规模测相机交互。帧率数据对应本机显卡和测试视口。预测耗时会随时间范围、对象轨道、缓存和后台负载变化。[帧率记录](./evidence/phase9-render-2026-11-21.json) · [首屏记录](./evidence/phase9-warm-load-2026-11-21.json) · [接口与预测记录](./evidence/phase9-api-2026-11-21.json)

## 稳定性与缺陷关闭

- 重新计时后的连续运行达到 1,800 秒，共 24 轮切页、跟踪或回放操作。主动中断 WebSocket 后完成新握手。页面离开探索区后释放场景，返回时仅有一个活动地球实例。采样期间 JavaScript 堆有波动，无持续单调增长。[连续运行记录](./evidence/phase9-soak-2026-11-21.json)
- 修复实时场景刷新时重置卫星跟踪。刷新更新原有绘制实体，回归中在跟踪状态触发两次场景请求，目标和跟踪状态保持，退出操作正常。[复测](./evidence/phase9-interaction-2026-11-21.json)
- 修复上游失败后有效快照校验信息丢失。成功快照与最近请求状态分别记录。空库遇到无法校验的旧快照时保留失败记录，随后导入随项目提供的代表性样本。本机实测成功恢复 3 个初始对象，完整目录仍需有效上游快照或后续成功采集。[空库启动](./evidence/phase9-bootstrap-2026-11-21.json) · [后端回归](./evidence/phase9-phase2-backend-2026-11-21.xml)
