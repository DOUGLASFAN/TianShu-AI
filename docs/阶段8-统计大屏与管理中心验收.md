## 使用入口

导航“态势大屏”进入独立 `/dashboard`。顶部为活跃目录载荷、活跃目录收录、分组和地磁观测；中部为互斥轨道分布、国家／组织、用途、近十二个月发射卫星数量，以及真实三维地球。中心明确标记实际绘制的代表卫星数量，点击点位或榜单可选中卫星，显示其轨迹与当前推算参数；详细操作进入探索工作台。

底部榜单默认展示最新导入根数，分别给出根数历元和来源采集时间，不冒充遥测。可选择自己的观测站，展示该站最近保存的已完成预测中的未来过境；无结果时明确说明并给出规划入口，不生成示例事件。站点已修改或计算依据陈旧时保留原快照提示。榜单支持主动暂停、鼠标悬停暂停、键盘焦点暂停；减少动态效果时默认暂停。

大屏采用独立 1920×1080 画布，按实际容器等比缩放和居中留边；工作台页面保持布局自适应。大屏临时取消文档滚动条槽位，离开后公共布局恢复；视口变化同时重置容器的隐藏滚动偏移，避免焦点导致边缘裁切。全屏申请失败有提示且继续可用，支持页面按钮退出和浏览器退出。地球按容器视场容纳完整球体，不沿用探索页的大球裁切取景。

管理员的“系统管理”包含数据源、任务与日志、用户管理、操作记录。数据源显示最后尝试、最后成功、下次调度、有效数据年龄、条数、耗时与错误代码；任务和采集记录分别查询、筛选、分页，详情使用右侧抽屉。手动任务返回持久 ID，重复提交返回同一活跃任务；用户启停需确认，历史会话撤销，唯一可用管理员不能停用。

## 统计口径

图表分母统一为 `active` 分组中的唯一 NORAD 记录，采用 `IN/EXISTS`，不将重叠分组相加。总收录量和不在当前活跃分组的历史记录在口径浮层另列。指标“活跃目录载荷”仅识别来源标为 `PAY/PAYLOAD` 且无衰减日期的记录，不冒充全球完整在轨载荷总量。

轨道分类复用目录筛选的同一 SQL 表达式，按下表顺序互斥匹配。半长轴由平均运动和地球引力常数推算，地球参考半径取 6378.137 km。

| 分类 | 项目统计规则 |
| --- | --- |
| 未知 | 平均运动缺失／不在有效范围、偏心率缺失／越界、近地点低于地表 |
| LEO | 远地点小于 2000 km |
| GEO | 周期距 1436 分钟小于 30 分钟且偏心率小于 0.1，含倾斜同步轨道，不声称全部静止 |
| MEO | 未命中前项、远地点小于 35786 km 且偏心率小于 0.25 |
| HEO | 其余高轨／高偏心对象；此处不是只指高椭圆轨道 |

平均运动先转为安全空值再做除法，零值不会导致整份聚合查询失败。各分类数量之和必须等于活跃目录数量。

国家／组织与用途占比保留未知项；前四类外合并为“其他”，未知不并入其他。仅使用来源明确提供的 `PURPOSE`，不根据卫星名称或星座推断。当前用途覆盖为零时，真实展示未知 100%，不以假分类填图。

发射趋势逐颗统计目录中的合法、非未来发射日期，覆盖近十二个日历月，当前月尚未结束。非法日期和缺失日期归入未知；零值表示该月当前目录中没有已知发射记录，不表示全球实际没有发射。图表明确为卫星颗数，不是火箭发射次数，且展示整个活跃目录的日期覆盖数。

统计每五分钟聚合，写入 PostgreSQL 持久快照和 Redis 缓存；Redis 不可用仍能返回数据库快照。API 返回生成时间、源采集时间、缓存年龄和上次任务状态，过期值保留并标记。首个缺失／旧结构快照按当前数据库生成，不填随机数字。旧 `catalogCount/ownerKnownCount/ownerUnknownCount` 字段继续按总收录范围兼容，图表覆盖字段明确按活跃范围。

## 任务与管理的一致性

新增迁移 `a3d839618e28`，建立 `job_runs` 与 `admin_audits`，保留既有用户、目录、预测、计划和采集原文。已有 `collection_runs` 仍保存真实来源采集记录；新任务表补齐轨道、元数据、ISS、统计、天气及恢复检查的统一调度历史。

- 每类任务有 PostgreSQL 会话租约，数据库部分唯一索引限制同类只能有一个排队／运行任务；手动创建再以事务锁去重。
- 同类手动刷新至少间隔 60 秒，先返回已有活跃任务，再执行限流。空间天气来源共享整批任务，单个刷新按钮不会创建六份并行重复采集。
- 排队手动任务优先于自动调度占用租约，避免自动调度每秒先抢锁而使手动任务饥饿。队列持久化，API 请求结束不会丢失任务。
- 持有租约后发现旧运行记录说明旧执行者已不在；旧记录明确记为 `WORKER_INTERRUPTED`，新尝试建立新记录，不把旧失败改写成成功。
- 成功、失败、部分失败分别保存。天气批次只要有子来源失败就标记“部分失败”并保留各子结果；全部失败标记失败，不用一个成功状态掩盖来源失败。
- 元数据缺失字段不擦除已知字段；重复编号和结构错误拒绝整次更新。缓存命中保留原始来源时间，不把本次读取时间当成新数据时间。
- 管理成功操作保留操作者、动作、对象和时间。手动任务保留 HTTP 请求 ID；详情只展示安全结果和受控错误代码，不返回密码、票据、连接字符串或异常堆栈。
- 启停账户使旧会话失效；重新启用不恢复旧票据。锁住管理员集合后检查最后一位可用管理员，普通用户不能绕过路由菜单调用管理 API。

ISS 保留原来的定时请求超时；恢复检查可使用验证 TLS 的有界替代传输，仍经过同一编号、单位、数值范围与源时间校验，不绕过验证。

## 故障演示与真实恢复

只有管理员可以开启全局外部数据源故障演示。演示状态持久化，所有用户及独立大屏持续显示标记。新轨道、元数据、ISS 和天气外部任务在来源门禁处主动失败，日志代码为 `DEMO_SOURCE_FAILURE`；本地统计、已保存数据、轨道传播、预测和提醒继续工作。开启操作幂等，不因重复点击生成无限任务。已开始的请求可能完成，其真实结果不被改写。

关闭演示立即解除注入，同时进入“正在检查”状态，建立独立恢复任务。实际检查 ISS、CelesTrak 小范围 GP／元数据、NOAA Kp、GFZ Kp 的连通性与格式；Kp 还检查数据时效。GP 需通过真实根数解析，元数据需有实际元数据字段。检查只验证列出的产品，不冒充全量目录重新采集成功，也不替代 NASA 等独立来源状态。

全部检查通过后关闭全局提示；有任一检查失败，恢复任务记为失败并保留真实检查结果，提示“演示已关闭，上次恢复检查部分来源未通过”。此时注入已经停止，不把真实连接失败伪造为正常，也不声称本地系统整体不可用。管理员可在限流范围内再次检查，各数据源自己的失败与历史仍然保留。
