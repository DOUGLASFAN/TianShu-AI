## 3. 已核对的官方来源

### 3.1 轨道根数：CelesTrak GP

接口：`/NORAD/elements/gp.php`。以 `CATNR` 查询单目标，以 `GROUP` 查询分组，显式指定 `FORMAT=JSON`。查询参数名称使用大写；分组值按官方目录维护，不依赖未经验证的别名。

采用结构化 GP JSON 作为主要接入格式，TLE 为兼容输入。官方已明确传统 TLE 的五位编号限制，项目编号不能使用五位定长字符串；数据结构按最多九位编号设计。JSON 中部分固定的 OMM 元信息可以按官方语义补齐，不能把缺省误判成任意坐标系。

依据：[GP 官方格式说明](https://celestrak.org/NORAD/documentation/gp-data-formats.php)。

| 上游字段 | 本地语义/字段 | 检查与处理 |
| --- | --- | --- |
| NORAD_CAT_ID | noradId，跨来源关联键 | 正整数、最多九位；去重，不把名称当唯一键 |
| OBJECT_NAME / OBJECT_ID | 名称 / 国际编号 | 允许来源中的未知项，保留原文与可空状态 |
| EPOCH | 根数历元，UTC | 与 fetchedAt 分开保存，采集新不代表历元新 |
| MEAN_MOTION | 平均运动 rev/day | 有限且大于 0；不是地面速度 |
| ECCENTRICITY | 偏心率 | 当前地球卫星 SGP4 接入要求 0≤e<1 |
| INCLINATION | 倾角 ° | 0～180，保留精度 |
| RA_OF_ASC_NODE / ARG_OF_PERICENTER / MEAN_ANOMALY | 角度参数 ° | 有限数值，供后续传播库使用 |
| BSTAR / MEAN_MOTION_DOT / MEAN_MOTION_DDOT | 阻力及平均运动导数字段 | 不自行猜测缩放，后续按传播库 OMM 接口验证 |
| 默认 OMM 语义 | EARTH / TEME / UTC / SGP4 | 依据官方定义补齐，显式返回其他值时不得覆盖 |

## 4. 调用策略与项目调整

根据 [CelesTrak 使用政策](https://celestrak.org/usage-policy.php)，同一更新周期内共享结果；GP 采用 2 小时刷新，SATCAT 采用每日保守刷新，配置需适应来源变化。目录更新时间查询本身也要限频。

- 后端统一采集，前端和每个用户不直接请求上游；搜索分页查询本地库。
- 单域串行、限制响应体，HTTPS 验证开启，不自动跟随重定向，首个错误即停止后续请求。
- 收到非 200（含重定向/限流/服务异常）停止该来源并报告，不进行自动重试；修复 URL 或完成原因审查后才安排下一次采集。
- 网络错误也不无限重试。本次脚本保存失败记录，重跑默认在 TTL 内不再次联网；网络条件修复后可用显式审查说明复查传输错误。
- 成功保存原文、URL、采集时间、HTTP 元信息及 SHA-256；只把通过校验的版本交给后续业务。HTTP 200 但内容为 HTML、空数据或字段不合法不能判成功。
- 对根数历元计算年龄分布、旧数据数量；有未来历元时单独列出，不用采集时间掩盖。

项目原先“有限重试与退避”的通用方案在 CelesTrak 适配器中受以上停止规则约束；WebSocket 客户端重连与这个上游策略是两件事。

## 5. 失败时的替代与降级

1. 优先使用本机最后一个有效缓存/数据库版本，展示原始来源与年龄；本次已取得六份有效原始响应缓存，正式业务数据库尚未建立。
2. 可以导入用户合法获取的 CelesTrak JSON/CSV 文件，保留来源、下载时间、哈希并校验；必须标为导入快照，不能据此声称在线采集成功。
3. 若持续无法使用，评估有官方授权和必要账号的数据源，先验证许可、字段、更新频率与实际可用性，再决定替换。不能把未经验证的公开镜像直接加入生产配置。
4. 没有有效数据时明确不可用；不随机造位置和统计，不将合成测试数据用于答辩实时数据。

本次未验证其他服务，不把备选计划写成已接入。再次出现连接问题时直接保留原有效版本、记录错误并按政策停止，不重复安装环境或重做设计。
