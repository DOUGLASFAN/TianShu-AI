## 行为与范围

探索页与态势大屏共用地球渲染器。远景保留本地 8K 地表、夜光和合成云层；镜头从约 3000 km 缩近到 700 km 时，太空材质连续渐隐，露出按需加载的在线底图。不会重新创建地球、清空卫星或重置回放时钟。最小缩放高度由 100 km 降至 150 m。

探索页、观测规划与新建／编辑观测站都提供“底图”入口，可切换影像、街道。影像可开关地名；街道图本身包含文字，因此该模式下地名开关禁用，不能假装可以去掉原图文字。观测站定位按钮将镜头定位到站点周边约 100 km，随后可继续缩近。态势大屏默认保留太空远景。

底图用于地表定位，不提供建筑三维模型或实时卫星摄影。影像清晰度与年代由所在地区的数据覆盖决定。道路图当前可能包含英文地名，不能承诺全中文全球底图。

## 数据与坐标

默认使用 Esri 公开 MapServer 的 World Imagery、World Street Map 与 World Boundaries and Places，采用标准 Web Mercator 图块；上游路径为 `tile/z/y/x`，本地接口为 `z/x/y`。Cesium 内部自动投影，观测站输入、点选和数据库继续统一为 WGS84，不对卫星或站点套用 BD-09／GCJ-02 偏移。

百度开发者 AK 只适用于相应的百度官方服务，不能替代天地图 Key。本次不接入百度瓦片，不抓取其内部接口。将来接入百度地点搜索时，应单独使用官方服务及坐标转换流程。

天地图官方 WMTS 适配器已预留，可在根目录私有 `.env` 设置 `STAR_TIANDITU_KEY`；当前未提供该 Key，因此此来源尚未完成在线验收，不默认选用。`STAR_MAP_PROVIDER=auto` 在无天地图 Key 时选择 Esri；可设为 `local` 强制使用本地贴图。`STAR_ARCGIS_TOKEN` 为可选私有令牌，是否适用于所选服务应按实际授权确认。

## 请求与回退

浏览器通过带登录凭证的同源接口请求图块，开发者 Key 留在服务端。接口仅允许命名来源和图层，校验级别、行列范围、响应大小及 PNG／JPEG／WebP 文件头，限制同时 8 个外部请求。Windows 公开图块通过验证证书的本机 curl 请求；私有凭证 URL 不传入子进程命令行。上游错误不会把完整 URL 或密钥返回给浏览器。

本地 8K 贴图始终作为最底层。每个失败图块最多自动补试一次，之后可手动重试；单块失败不清空已经显示的图像，没有在线内容时保留本地地球，提示无法提供街道细节。不会无限重试。图层切换和弹窗关闭会释放对应资源。

上游元数据声明 `exportTilesAllowed=false`。本实现只做交互所需的在线请求，响应 `private, no-store`，不持久化服务商瓦片、不批量预取、不制作离线城市包。离线可用的是既有本地地球纹理，并非离线街道地图。

## 来源与使用边界
