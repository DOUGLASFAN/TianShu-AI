# 星枢 · 全球卫星态势与观测平台

产品需求文档 PRD v1.0｜2026-11-11

状态：产品方向与核心范围已确认；本文件中的参数、技术方案及验收指标为据此制定的首版开发基线，可在验证后通过变更记录调整。

## 1. 项目目标与背景

本项目用于“卫星数据可视化大屏系统（前后端交互版）”结课作业，主要目标为课程高分，同时形成可完整演示、计算有依据、交互与视觉精致的个人作品。个人从零开发，2026 年 12 月上旬交付，具体答辩日期待课程通知。

平台面向全球公开编目卫星，不局限于北斗。通过真实三维地球连接卫星探索、地面观测规划、空间天气与数据可信度，形成“了解全球态势—选择卫星—查看轨道—选择观测站—预测过境—保存计划—获取提醒”的完整链路。

运行方式为本地电脑展示，允许免费注册和申请数据服务 Key，优先零付费实现。必须包含独立前端、后端和持久化数据库，不能以静态页面或假接口替代业务功能。

### 1.1 成功标准

- 课程验收 A-1～A-10 全部有可演示证据。
- 六个主要页面的核心业务可以实际操作，保存的数据重启后可回查。
- 三维地球、轨道、跟踪与过境回放视觉连贯，关键动画可以中断、跳过或取消。
- 外部接口异常、WebSocket 断开、数据过期时仍能使用已保留的数据，并准确提示状态。
- 答辩能讲清数据来源、轨道计算、业务规则、性能设计与系统边界。

### 1.2 首版范围与边界

首版必做：全球目录、分组展示、卫星详情与跟踪、点位观测站、几何过境及目视窗口预测、过境回放、观测计划、站内提醒、空间天气、数据质量、大屏、账号与管理、部署与答辩材料。

可选增强：浏览器桌面通知、观测结果 CSV 导出、演示导览。不能作为核心流程依赖。

不纳入首版：多边形区域分析、真实碰撞概率计算、实际侦察任务识别、传感器覆盖推断、定位精度评估、射频信号监测、全网历史轨道归档、短信与邮件通知、移动端完整三维工作台。

“全球”指已接入的公开编目目录及相应数据覆盖，不声称覆盖全部实际在轨目标；“当前位置”通常是根据轨道根数计算的位置，不声称是实时遥测。

## 2. 用户与权限

| 角色 | 权限 |
| --- | --- |
| 未登录用户 | 登录、注册；业务 API 返回 401，不提供匿名绕过模式 |
| 普通用户 | 探索、统计、天气、预测；管理自己的关注、观测站、计划和通知 |
| 管理员 | 普通用户全部能力；数据源状态、任务触发、采集日志、用户启停 |

提供普通用户和管理员各一个本地演示账号。注册只能创建普通用户，不能提交管理员角色。密码使用安全哈希保存，环境配置和启动文档说明演示凭据。

用户只能访问自己的私人资源；越权请求不得泄漏其他人的内容。管理员业务入口有独立权限校验，禁用用户后其登录与后续访问应失效。

## 3. 信息架构与页面需求

### 3.1 卫星探索 `/explore`

默认首页，以三维地球为主体，侧边目录和详情面板提供操作。顶部包含导航、时间模式、连接与数据状态、账号入口。

- 搜索支持名称和 NORAD 编号，列表有分页、总数、清空和无结果状态。
- 筛选支持分组、轨道类型、国家/组织、用途；缺失元数据统一归为“未知”。
- 提供空间站、北斗、GPS、Galileo、Starlink 等快捷分组，以实际接入结果为准；无数据时禁用并说明。
- 目录支持全量查询；默认地球展示代表分组或受控数量点位，另有全目录点位总览。
- 探索页提供「实时态势」与「轨迹回放」。实时态势跟随当前时刻，可开关全球总览；轨迹回放提供采样范围、拖动和倍速，默认回放代表卫星及所选卫星，也可加载采样方案。进入回放后，本次回放区间与时钟独立于实时刷新。数据状态分别展示画面时间、根数历元、目录成功采集时间、连接与总览窗口。
- 探索页默认使用北京时间（UTC+8），支持切换为协调世界时（UTC），浏览器记住选择。画面时钟、回放范围、精确时间输入和数据状态使用同一显示时区，切换时保留对应的绝对时刻。
- 根据缩放与选择状态控制标签数量。默认仅选中卫星绘制完整轨道，同时显示的关注轨道默认上限 5 条。
- 点击列表或地球点位，同步选中、显示标记、打开详情；不无条件强制飞行，提供“定位”和“跟踪”按钮。
- 详情包含名称、编号、国际编号、所属分组、国家/组织、用途、发射日期、轨道类型、当前经纬度、高度、速度、倾角、周期及数据时间。缺失字段不编造。
- 支持关注/取消关注、进入观测规划、切换跟踪、退出跟踪、恢复全球视角。
- 区分空间轨道与地面投影轨迹；跨越日期变更线时不得错误横穿整张地图。
- 用户旋转或平移地球时，可退出相机锁定并明确反馈，卫星选中状态保留。
- 星下点不等于成像覆盖范围，不展示未经数据支持的侦察覆盖锥。

### 3.2 观测规划 `/observations`

主流程：选择或创建观测站 → 选择卫星/分组 → 设置时间与最低仰角 → 计算 → 筛选结果 → 查看详情和回放 → 保存计划。

- 观测站支持地球/地图点击选点、手工经纬度输入、名称及海拔；不依赖地址地理编码。海拔默认 0 米并可编辑。
- 经度范围 [-180,180]，纬度范围 [-90,90]，海拔单位为米；输入非法时在字段旁提示。
- 支持保存、编辑、删除和设置默认站；删除已被计划引用的站点时优先软删除，保留计划快照。
- 查询时间为未来 24 小时、3 天、7 天，默认 24 小时；最低仰角默认 10°，允许 0°～90°。
- 支持单颗卫星和分组查询。分组预测采用后台任务，单任务默认上限 500 颗；更大分组先按编号稳定分页选定批次并显示实际预测对象范围，不能静默截断。
- 超限、排队、计算中、取消、失败、无过境、轨道数据不可用均有独立反馈。
- 结果展示卫星、进入时间、最高点时间、离开时间、最大仰角、持续时间、方位角、潜在目视窗口、数据质量。
- 可按时间和最大仰角排序，按“可能适合目视观测”筛选；结果支持分页。
- 详情显示仰角随时间变化曲线、地面轨迹和受光/地面昼夜条件。
- 回放分为单星与整组两种模式。单星时间固定在选定事件附近；整组覆盖提交批次全部对象（最多 500 颗）和完整查询时间，不受事件分页、排序或目视筛选影响，没有过境的对象也保留点位。
- 两种回放均可播放、暂停、拖动、指定时间、键盘定位、调速及退出。整组切换卫星或点击点位时保持模拟时刻，选中星显示名称、轨迹、地面投影与当前窗口仰角曲线；可只看达到站点仰角要求的对象，该状态不等于肉眼可见。
- 整组轨迹按时间窗口加载，时间轴始终是完整查询范围；越出已载入窗口时显示加载状态，不外推，也不把载入失败对象冒充不存在。不改变实际提醒的系统时钟。
- 查询范围内已在过境或结束时尚未离开的事件标记“跨查询边界”，不伪造完整起止点；持续可见卫星单独说明。

### 3.3 空间环境 `/environment`

- 展示地磁活动指标、数据时间、近期趋势，以及公开空间天气事件和通知。
- 首选 NOAA SWPC 获取 Kp 与相关等级信息，NASA DONKI 补充耀斑、日冕物质抛射等事件；每个来源需通过接入验证。
- 事件详情包含来源、发布/发生时间、类别、原始等级或描述、原始链接、潜在影响解释。
- 观测值、预测值和官方预警分别标注。来源没有等级时不自行杜撰“官方等级”。
- 对导航、通信等展示一般性潜在影响说明，不推断指定地点已经发生故障。
- 数据缺失或过期时显示“状态未知/数据过期”，不能显示绿色“正常”。
- 支持事件类型与时间筛选；详情可返回原列表状态。

### 3.4 态势大屏 `/dashboard`

- 1920×1080 为设计基准，等比缩放并居中留边，无页面滚动条。
- 指标包括已收录在轨载荷数、活跃目录收录数、分组数、当前空间天气状态；附覆盖范围和统计时间。
- 展示 LEO/MEO/GEO/HEO 轨道分类、近 12 个月卫星发射数量趋势、国家/组织占比、用途占比、实时动态榜单。
- 中央地球展示代表分组与选中卫星；滚动榜单可选观测站未来过境事件，鼠标悬停暂停滚动。
- “发射趋势”明确统计的是发射卫星数量，不能标成火箭发射次数。元数据覆盖不完整时显示覆盖率和统计范围。
- 支持全屏进入/退出；浏览器拒绝全屏时页面仍可正常展示。
- 连接断开、最后更新时间、缓存/快照来源在大屏可见。

### 3.5 我的空间 `/workspace`

- 关注列表：搜索、移除、定位卫星、进入预测；关注关系去重且持久化。
- 观测站：增删改查、默认站设置。
- 观测计划：保存预测事件、查看快照、取消、重新计算，按即将开始/已结束/已取消分类。
- 通知中心：未读数、已读、全部已读；站内提醒默认在开始前 10 分钟产生，可在保存计划时选择 5/10/30 分钟。
- 轨道更新后计划保留原始计算依据，标记“建议重新计算”；用户确认重算后更新计划与提醒版本。
- 同一计划同一版本同一提醒阈值只产生一次通知。取消计划撤销尚未发送提醒。
- 应用关闭时不承诺提醒；重启时为已过期计划显示错过状态，未来计划恢复调度。

### 3.6 管理中心 `/admin`

- 数据源面板展示最后尝试时间、最后成功时间、条数、延迟、缓存年龄、错误摘要和下次计划时间。
- 查看轨道、元数据、ISS、空间天气、统计等采集任务状态与历史记录。
- 手动刷新需限流、去重并返回任务 ID；重复点击不创建同类并行采集。
- 日志可按来源、结果、时间分页筛选，错误信息脱敏。
- 用户列表支持分页、角色查看、启用/禁用；不允许管理员禁用当前唯一可用管理员。
- 提供管理员可控的“外部数据源故障模拟”，明确标识演示状态，用于验证降级；不伪造正常采集成功记录。

### 3.7 采样管理 `/sampling`

- 登录后的独立页面。用户可新建、编辑、删除、加载本人保存的采样方案，按名称或 NORAD 编号选择卫星。
- 主页面显示采样参数、已选卫星、预计点数及试算和保存操作。通过「选择卫星」打开独立窗口，在窗口内浏览分组、搜索目录和查看已选项。应用后写入表单，取消或按 Escape 放弃这次修改。
- 预设按导航星座、观测与通信组织。GNSS 总览汇集北斗、GPS、伽利略、GLONASS、QZSS 和 NavIC，另提供空间站及相关飞船、Landsat / Sentinel 对地观测和星链。组成员来自本地公开目录及空间站已有分组，数量随本地目录更新。可以按批浏览、跨组混选、用本批替换当前选择。方案保存实际选中的编号。
- 支持固定北京时间区间，或以当前时间为基准设置起点偏移和时长。相对方案每次加载按当时所在分钟重新确定起点。支持 10、20、30、60、120、300 秒采样间隔。
- 试算展示实际区间、每颗卫星的点数、根数来源、历元与推算失败信息。加载到卫星探索后从区间起点暂停，支持选择方案卫星、拖动时间轴和倍率播放。可导出地固坐标、速度、历元、根数版本与采样时间的 JSON。
- 每个方案最多 12 颗卫星、24 小时、12,000 点，计算区间须在当前时间前后 7 天内。固定方案保存时间和参数，加载或导出时使用本地目录中当前的轨道根数重新计算。已导出的文件保留当次结果。业务范围为公开卫星的轨迹推算与探索回放。

## 4. 核心计算与数据口径

### 4.1 坐标、时间与单位

- 后端统一使用 UTC、ISO 8601 带时区时间；界面默认 Asia/Shanghai，明确显示 UTC+8，可切换 UTC。
- 观测站使用 WGS84 经纬度；展示高度 km、速度 km/s、角度 °，输入站点海拔 m。
- 后端负责轨道传播、坐标转换、轨道分类、过境与受光判断；前端只做渲染、坐标投影和已计算采样点插值。
- 轨道数据同时记录 epoch（根数历元）与 fetched_at（采集时间），不能用刚采集掩盖旧历元。
- 轨道以 SGP4 传播，不用简单圆周动画替代计算。传播失败的对象应单独标记，不送出 NaN 坐标。

### 4.2 几何过境与目视窗口

- 几何过境为卫星相对观测站的仰角达到所设阈值的时间区间，并计算区间内最高点。
- 潜在目视窗口要求同时满足：达到仰角阈值、观测站太阳高度低于 -6°、卫星受到太阳照射。太阳高度阈值展示在结果说明中。
- 条件需在过境区间内采样并细化边界，输出可分成多个子区间，不能只用最高点一次受光判断覆盖整次过境。
- 首版细化窗口边界到约 1 秒的数值分辨率；这不是实际预测精度保证。
- 首版不考虑云量、光污染、建筑遮挡和准确视星等；满足条件也不保证肉眼能看见，不将所有通信/导航卫星标为肉眼可见。
- 结果保留观测站、根数版本、算法版本、阈值、计算时间，允许复核和重复计算。

### 4.3 轨道分类与统计

- 采用有版本的项目分类规则，互斥分配到 GEO、HEO、LEO、MEO 或未知，不将分类规则表述为唯一行业标准。
- 首版建议顺序：GEO（周期接近恒星日、低偏心率、低倾角）→ HEO（高偏心率）→ LEO（远地点高度不超过 2000 km）→ MEO（位于低轨上界与地球同步轨道高度之间）→ 未知/其他。
- 详细阈值在算法设计时固化为配置，并用代表卫星校验；页面提供口径说明，“未知/其他”不强行归入四类。
- 卫星可以属于多个分组，组内去重按 NORAD 编号；全球数量不能简单相加分组数量。
- 活跃指上游 active 目录归属，不能推断卫星设备健康。国家/组织按来源归属编码展示，不能当作物理所在地。
- 发射日期、用途等来自元数据；缺失时保留未知。必要的人工补充须有来源、维护时间及覆盖范围。

### 4.4 数据可信度与降级

- 数据状态分为：可用、陈旧、降级、不可用；单独记录是否使用演示快照。
- 状态必须包含原因、来源、历元、采集时间及数据年龄。状态阈值是项目规则，不代表官方轨道误差评级。
- 首版默认根数历元年龄超过 3 天提示陈旧，超过 7 天提示强警告；高于阈值仍允许明确确认后进行带警告预测，传播失败则禁止。
- 外部接口失败按“内存/Redis 缓存 → 数据库最近有效记录 → 已准备快照 → 不可用”回退。
- 断网模式保留本地合法授权的地球贴图、关键静态资源与星历文件；不依赖在线瓦片才能显示基础地球。
- 快照保留原始时间，画面显著标注“演示快照”，不能随系统时钟改写来源时间。

## 5. 动画与视觉体验要求

### 5.1 视觉方向

用户已选定 A「写实航天」为主要视觉方向。详细实施依据见[视觉与交互规范](./视觉与交互规范.md)、[交互原型文档](./交互原型文档.md)及[素材清单](./design-concepts/素材清单与提示词.md)。静态概念图用于风格参考，不代表动画与功能已实现。

真实地球、克制的深色专业界面、清晰的中文排版。深蓝灰作为背景，青蓝作为交互强调色，琥珀色提示风险，红色只用于严重异常。颜色同时配合图标与文字，不只用颜色表达状态。

地球是主要视觉中心；控制面板、指标与轨道标签有明确层级。避免装饰边框、持续闪烁、无信息粒子或过强发光影响阅读。图表统一轴线、图例、单位、提示框与空状态。

探索页采用自适应布局，大屏页单独采用等比缩放；1440×900、1920×1080、2560×1440 完成布局检查。普通内容缩放到 200% 时核心表单仍可操作。

### 5.2 必做动效清单

| 场景 | 行为及验收要求 |
| --- | --- |
| 首次进入 | 地球由远及近、主面板分层出现；资源就绪后播放，可跳过且不重复阻塞操作 |
| 卫星定位 | 相机沿平滑路径移动，目标标识与详情同步；连续选择只保留最后一次定位 |
| 跟踪 | 相机平滑锁定目标，避免瞬移、穿地和视角剧烈翻转；退出可恢复自由操作 |
| 卫星运动 | 后端采样与前端插值保持连贯，跨采样批次不明显跳变；超出有效范围提示等待或停止 |
| 轨道显示 | 渐显或方向提示准确，选择切换无旧轨道残影，不以轨道流光冒充实际运行速度 |
| 面板与列表 | 开合、筛选、选中和布局变化过渡一致；快速操作可中断，数据状态不丢失 |
| 过境回放 | 时间轴、卫星位置、轨迹与曲线游标同步；拖动后立即对齐同一模拟时刻 |
| 图表与数字 | 首次加载和更新有适度过渡；实时数值不过度跳动，不在每次推送后重播整图 |
| 异常恢复 | 连接与数据状态平滑切换，提示不遮挡地图关键操作 |

普通微交互参考 120～250 ms，面板与布局参考 200～400 ms，相机定位参考 0.8～2 秒；根据距离调整，长动画提供跳过。支持 reduced-motion 设置，关闭非必要动画。键盘焦点、弹窗退出和加载状态必须完整。

### 5.3 动画工程约束

- React 组织页面与交互；Cesium 独立管理三维渲染循环，不逐帧通过 React state 更新所有卫星。
- Motion 负责界面进入退出、布局与手势反馈；GSAP 仅用于需要编排的少量演示时间线，同一元素的同一属性由一个系统控制。
- 页面卸载或切换必须释放订阅、定时器、WebGL 资源和动画。避免重复创建 Cesium Viewer。
- 不同时引入另一套三维引擎渲染同一个地球；特殊视觉需求先验证 Cesium 能力和性能。

## 6. 数据源、刷新与持久化

| 数据 | 首选来源 | 默认刷新/缓存 | 异常处理 |
| --- | --- | --- | --- |
| 卫星轨道根数 | CelesTrak GP，兼容 TLE 与结构化 GP 格式 | 每 2 小时采集；记录版本 | 最近有效版本、快照与过期提示 |
| 元数据 | CelesTrak SATCAT 可用数据及有来源的补充 | 每日 | 不覆盖有效字段为未知，保留历史 |
| ISS 接口位置 | Where the ISS at | 每 10 秒，Redis 缓存 | 明确切换为轨道推算，不伪称接口实测 |
| 空间天气 | NOAA SWPC、NASA DONKI | 按产品粒度配置，默认 5～15 分钟 | 缓存、过期/未知提示 |
| 聚合统计 | 本地数据库与后端统计服务 | 缓存 5 分钟 | 最近一次统计与范围说明 |
| 星历和地球资源 | 合法许可的可本地保存资源 | 首次准备并校验 | 本地基础地球，缺失时明确报告 |

实现前逐项验证端点、字段、配额与使用条款。表中刷新频率是初始方案，上游限制更严格时按上游限制调整并记录。第三方调用全部由后端发起，前端仅访问自有 HTTP/WS 服务及本地资源。

轨道更新必须校验后原子切换有效版本，部分解析失败不能清空原目录。定时任务单实例执行，具备超时、有限重试、退避、去重及任务日志。客户端切页不得触发新一轮外部采集。

CelesTrak 适配器按已核对的来源政策优先执行停止规则：非 200 响应停止该来源并审查，不能套用通用自动重试；本轮源验证采用无自动重试。结构化 GP JSON 为主要输入，TLE 作为兼容输入。SATCAT 不提供完整用途字段，用途统计必须标明映射依据与未知项。实际来源验证状态见[轨道与元数据来源验证](./轨道与元数据来源验证.md)。

## 7. 技术方案基线

| 层次 | 方案 | 目的 |
| --- | --- | --- |
| 前端 | React + TypeScript + Vite | 页面与交互开发 |
| 地球与图表 | CesiumJS + ECharts | 地理空间、时间动态和统计展示 |
| 界面与动效 | Tailwind CSS + Radix UI、Motion；GSAP 按需 | 定制视觉、可访问交互及动画编排 |
| 前端状态 | Zustand + TanStack Query + React Router | 工作台状态、服务端数据与路由 |
| 后端 | Python FastAPI + Pydantic | HTTP、鉴权、WebSocket 与输入校验 |
| 轨道计算 | Skyfield / SGP4 | 位置、过境与太阳受光计算 |
| 持久化 | PostgreSQL + SQLAlchemy + Alembic | 业务数据、约束与数据库迁移 |
| 缓存与任务 | Redis；独立后台任务进程 | 缓存、计算任务、采集与提醒调度 |
| 运行与验证 | Docker Compose + Nginx；pytest、Playwright | 本地启动、反向代理与核心验收 |

具体版本在工程初始化时验证兼容性后锁定，不依赖“始终最新”。不因框架选择承诺自动获得特定帧率。采集、批量轨道计算与过境任务不得阻塞 HTTP/WS 事件循环。

逻辑链路：浏览器 → Nginx → FastAPI → PostgreSQL/Redis；后台任务进程访问第三方来源和执行计算，经 Redis 发布更新，由后端按订阅推送。

## 8. 概念数据模型

| 实体/表 | 核心内容与约束 |
| --- | --- |
| users | 唯一用户名、密码哈希、角色、状态 |

| orbit_elements | 卫星外键、历元、采集时间、原始记录、格式、哈希和版本 |
| observation_stations | 所属用户外键、名称、经纬度、海拔、默认状态 |
| favorites | 用户及卫星外键，组合唯一键 |
| prediction_jobs / pass_predictions | 查询条件、状态、进度、根数版本、事件与窗口结果 |
| observation_plans | 用户、卫星、站点关联，预测快照、版本、状态、提醒设置 |
| notifications | 用户与计划关联、去重键、内容、已读状态 |
| space_weather_events | 来源、外部 ID、类型、事件时间、原始内容与版本 |
| collection_runs / data_sources | 采集状态、耗时、条数、错误摘要与来源配置引用 |

至少满足课程三张业务表要求，实际按以上领域设计。外键、唯一约束、常用查询索引在数据库设计中落实：卫星编号、根数的卫星+历元、用户资源归属、计划开始时间、事件时间和采集时间。

用户数据长期持久化；根数与采集日志首版默认保留 30 天，天气事件保留 90 天，任务明细可按容量清理。已保存计划引用的计算依据不随清理丢失；清理策略可配置。

## 9. API 与实时协议需求

自有 API 统一 `/api/*`，成功响应保留请求标识与数据来源元信息；分页必须返回 `{total, list}`，另可附 `page/size`。错误包含稳定错误码、可读信息和 requestId，不返回内部堆栈。

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| POST | /api/auth/register、/api/auth/login、/api/auth/logout | 注册、登录签发 Token、退出 |
| GET | /api/auth/me | 当前用户 |
| GET | /api/satellites | page/size/keyword/group 等分页筛选 |
| GET | /api/satellites/{noradId} | 详情及数据质量 |
| GET | /api/satellites/{noradId}/trajectory | 指定时段轨迹采样，限制范围与采样量 |
| GET | /api/dashboard/summary、/orbit-distribution、/launch-trend | 汇总、轨道统计、趋势；后两个同属 /api/dashboard 前缀 |
| GET | /api/dashboard/country-distribution、/purpose-distribution | 国家与用途统计 |
| GET/POST/DELETE | /api/favorites 及 /{noradId} | 关注列表、关注与取消 |
| GET/POST/PATCH/DELETE | /api/stations 及 /{id} | 观测站管理 |
| POST | /api/predictions | 创建预测任务 |
| GET | /api/predictions/{id}、/{id}/passes | 任务状态、分页结果 |
| POST | /api/predictions/{id}/cancel | 取消计算 |
| GET/POST/PATCH | /api/plans 及 /{id} | 列表、保存、取消/更新计划 |
| GET/PATCH | /api/notifications 及 /{id} | 通知与已读状态 |
| GET | /api/space-weather/summary、/events | 天气概览与事件 |
| GET | /api/admin/data-sources、/collection-runs、/users | 管理查询 |
| POST | /api/admin/data-sources/{id}/refresh | 手动采集 |
| PATCH | /api/admin/users/{id} | 用户状态管理 |
| WS | /ws/realtime | 卫星采样增量、状态、任务进度与通知 |

HTTP 业务请求携带 Authorization。浏览器 WebSocket 不能任意设置该请求头，采用后端签发的一次性短效连接票据握手，不能把长期 Token 放 URL；握手与订阅均验证权限，日志屏蔽票据。

实时消息包含 type、sequence、serverTime、data；位置条目包含 noradId、time、lat、lng、alt、velocity 及根数版本。坐标和单位遵循第 4 节。

- 初始快照 + 按需订阅增量，推送当前可视集合/选中对象，不默认向所有客户端广播全目录。
- 参考每 2 秒推送一批当前集合采样，选中对象提供足够时间采样供显示插值；具体频率按性能验证调整。
- 心跳、指数退避重连（参考 1/2/4/8/16/30 秒）、重连后补快照；暂停标签页可降低订阅量。
- 授权失败进入重新登录，不能无限重连；消息乱序按时间与序号处理，不回退到旧样本。
- 显示最后接收时间；超过 10 秒无期望数据提示延迟，断开显示重连中。数据新鲜度和连接状态分别表达。
- 任务取消、重复创建、数据过期与资源不存在有明确业务码；第三方故障正常走降级，不把上游 500 直接透传。

## 10. 性能、可靠性与质量验收

以下为工程目标，需记录本机配置、浏览器、数据规模和测试条件后实测，未验证前不表述为已达成。

| 项目 | 首版验收目标 |
| --- | --- |
| 三维默认场景 | 本机 Chromium，1080p，资源预热，2000 点+单条轨道交互时平均接近 60 FPS，连续操作无明显长卡顿 |
| 全目录总览 | 至少 10000 点基准场景目标不低于 30 FPS；自动降低标签和特效，并显示实际加载量 |
| 首屏 | 本地服务就绪、资源预热后 5 秒内进入可操作地球；冷启动单独记录 |
| 普通接口 | 本地缓存命中时分页、详情与统计 P95 不超过 500 ms，固定数据集至少 100 次测量 |
| 单星预测 | 7 天查询目标 5 秒内完成；超时不阻塞页面，允许后台等待 |
| 分组预测 | 1 秒内返回任务 ID；进度可见、可取消；500 星 24 小时目标 60 秒内，7 天单独实测与调优 |
| 稳定性 | 连续演示 30 分钟，反复切换页面和跟踪，不崩溃，资源释放后内存不持续单调增长 |
| 网络异常 | 数据源超时、断网、Redis 暂不可用和 WS 中断有对应状态，业务数据不损坏 |
| 持久化 | 重启服务后关注、站点、计划仍可回查，重复提交不产生重复关系 |
| 布局 | 大屏指定分辨率无滚动条，工作台三种分辨率不遮挡主要操作 |
| 访问控制 | 未登录 401、越权拒绝、普通用户访问管理接口拒绝 |

计算验证包括：固定根数与固定时间的参考向量、单位/坐标转换、事件起落点、持续可见与跨边界、多个受光窗口、时区、过期数据和 SGP4 失败；基于权威示例或独立参考结果交叉校验。数值算法容差和真实观测误差分开报告。

功能验证包括：注册登录、搜索分页、关注、保存站点、预测、计划与提醒去重、管理员任务、网络降级与重连的核心端到端流程。视觉验收保留各页面截图及三维交互录屏。

## 13. 风险与待验证项

| 项目 | 处理原则 |
| --- | --- |
| 数据源在本地网络不可达/限流 | 优先验证，合法代理与缓存；保留快照，不把快照当实时 |
| 全球元数据覆盖不齐 | 标明未知与覆盖率，必要时有来源地补充，不能伪造统计 |
| 全量点位与轨道计算开销 | 后端批量计算、按需订阅、分层渲染和性能预算 |
| 根数格式变化与新编号 | 存储编号不限制为五位，兼容结构化 GP；TLE 作为兼容输入 |
| 星历/图像许可及离线准备 | 记录来源与许可，安装准备阶段检查文件完整性 |
| 预测长窗口计算过慢 | 后台任务、分批、缓存、取消；实测后调整任务上限并记录 |
| 视觉效果与可读性冲突 | 优先清晰层级、准确状态与流畅操作，特效可降级 |

不再需要用户选择技术细节；实施中的常规决策按本需求自主推进。新增显著业务范围、改变已确认产品方向或涉及付费服务时再讨论。
