# 星枢手机端界面与验收

2026-11-25。用户复核发现，首轮把地图、时间控制、目录和详情排成了长页。即使入口可见，用户仍要在相距数屏的区域间跳转，找星、查看和定位失去了地图上下文。首轮的无横向溢出检查也遗漏了这个问题。

修订把地图作为常驻工作区，找星、详情与时间设置各用一张按需打开的底部面板。面板可以直接关闭，详情可返回当前搜索结果。定位和开始跟踪会收起面板并回到原画布。列表、轨道参数和设置的长内容在面板内浏览。沿用星枢深色底色、蓝色交互状态和琥珀色选中卫星。交互参考 [Apple 地图指南](https://developer.apple.com/design/human-interface-guidelines/maps) 和 [Apple 面板指南](https://developer.apple.com/design/human-interface-guidelines/sheets)。

| 页面 | 手机交互 |
| --- | --- |
| 应用导航 | 探索、目录、观测和「更多」固定为四个可见入口；二级菜单支持外部点按、Escape 和路由切换关闭。 |
| 卫星探索 | 地图和底部控制固定在同一视口。找卫星、所选卫星、实时与回放可直接点按。回放保留时间轴和倍率，精确时间及时区归入时间与数据面板。详情先显示定位、跟踪、预测和关注，三维模型按需展开。 |
| 卫星目录 | 名称、发射日期、NORAD 编号和归属合并展示，根数状态和关注仍可直接访问。点击卫星名称进入档案。 |
| 观测、采样与账户 | 表单加宽触控区，观测条件和结果可以互相跳转。观测站弹窗和采样选择器适配窄屏，登录输入使用 16 像素字号。 |
| 态势大屏 | 手机端以全宽滚动页面呈现指标、地球、分布和榜单，统计口径随内容阅读。桌面端保持 1920×1080 等比展示。 |

手机布局适用于宽度不超过 800 CSS 像素的视口，也覆盖宽度不超过 1000 像素、高度不超过 500 像素的粗指针设备。常用按钮按至少 44 像素高设计，页面边缘为浏览器安全区留出空间。

## 验收结果

- Edge 触屏模拟下，320×568、390×844、430×932 和横屏 844×390 的探索页整页滚动量均为 0。实际点按找星、返回搜索、定位、开始和退出跟踪、回放与设置。验证定位前后复用同一个地图 Canvas，关闭面板后焦点回到入口。跨页面共 35 次宽度检查通过，浏览器未记录未捕获异常。[修订版自动检查](./evidence/mobile-workbench-2026-11-25/mobile-layout.json)
- 1920×1080、1440×900、1024×768 共 24 次桌面路由对照通过。对照应用栏、导航、账号区、地球、时间控制和大屏画布的位置及尺寸。数据区对照位置与宽度，内容高度随实时数据和加载状态变化。[修订版桌面对照](./evidence/mobile-workbench-2026-11-25/desktop-layout.json)
- 既有应用栏与站点弹窗验证覆盖 15 次路由切换和三种弹窗大小。本次跨页流程重新点按观测站弹窗、采样选星、历史结果跳转和大屏滚动。[首轮应用栏与弹窗](./evidence/mobile-layout-2026-11-25/shell-layout.json)
- TypeScript 和 Vite 生产构建通过。浏览器验收使用 Edge 与软件 WebGL，iOS Safari 真机兼容性和移动设备 GPU 性能未实测。

运行中的本机项目可从 `frontend` 目录用 `node verify-mobile-layout.mjs` 复验。脚本使用已有演示账号和站点，不保存测试草稿。

## 五张手机截图复盘

2026-11-25。复查发现，首轮多处沿用了桌面端的展示顺序和对齐方式。时间面板继承了右对齐的工具布局。底图选项占据地图一角。目录用表格的列来组织手机内容，收藏比观测更显眼。观测规划按填写顺序组织页面，导致主要反馈画布排到长表单后。空间环境同时展开所有数据，趋势图在数据异步到达后没有重新测量容器宽度，图中文字随整幅图缩小。

| 区域 | 修订 |
| --- | --- |
| 探索与地图工具 | 时间设置按全宽行对齐，常用字段与数据详情分层。底图和太空缩小视觉面积并保留 44 像素触控区域。探索页同时只展开一个地图菜单，点选底图后收起菜单。 |
| 卫星目录 | 使用紧凑列表，每行放名称、编号、归属、「观测」和收藏。行内只提示需要注意的根数状态，发射日期和根数来源放在点开的档案里。 |
| 观测规划 | 先呈现当前卫星、观测站、快捷操作和地球。手动条件按需打开，历史计算独立可达。过境结果改为列表，保留进入、最高点、离开、仰角、时长和目视窗口。 |
| 空间环境 | 首屏并排显示观测与预测摘要，通报保留直接入口。趋势、通报和来源按需切换。趋势图根据实际宽度绘制，保留观测、预测、时效和来源语义。 |
| 采样管理 | 主页面直接显示「我的方案」列表和一个「新建」入口。新建与编辑共用弹窗，手机从底部打开，试算、保存和保存并加载固定在弹窗底部。应用选星后返回当前方案，保存成功后回到列表。 |

目录里的「观测」和规划页的「一键观测」进入同一过境预测流程。预设为当前时刻起 24 小时、最低仰角 10°。规划页使用当前选择的站点，目录进入时使用默认站点，无默认站时使用列表首站。缺少站点时打开条件区提示新建；陈旧或未来历元仍需确认。快速入口使用一次性导航状态，已提交后刷新通过任务地址恢复结果。

Edge 触屏模拟通过 35 次页面检查和 6 组交互。使用演示账号实测目录提交 ISS 任务，核对默认站、当前时刻、24 小时、10°，任务完成后刷新，POST 总数仍为 1。模拟无站点时提示新建且没有再提交。320 像素下额外验证通报筛选、来源记录、目录及档案，地球完整位于观测首屏内。三种桌面尺寸共 24 次布局对照通过，生产构建通过。本轮未做 iOS Safari 真机测试。[触屏联调](./evidence/mobile-refinement-2026-11-25/mobile-layout.json) · [窄屏数据](./evidence/mobile-refinement-2026-11-25/narrow-views.json) · [桌面对照](./evidence/mobile-refinement-2026-11-25/desktop-layout.json)

### 我的空间、采样管理与空间环境复审

2026-11-25。采用一致的文字层级和内容间距，在空态放置明确的后续操作，检查主要文字与背景对比度。[USWDS 排版](https://designsystem.digital.gov/components/typography/) · [IBM Carbon 空态](https://www.carbondesignsystem.com/building-blocks/core/patterns/empty-states) · [WCAG 最低文字对比度](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum)

- 我的空间的手机卡片间隔统一为 12 像素，关注名称与观测入口左右对齐。空计划直接引导至观测规划，新增站点表单按需展开。[手机截图](./evidence/mobile-observation-workspace-2026-11-25/utility-workspace-390.png)
- 采样空态说明方案用途，「新建方案」为唯一入口，仍使用原有的新建／编辑弹窗。[手机截图](./evidence/mobile-observation-workspace-2026-11-25/utility-sampling-empty-390.png)
- 空间环境将实测、预测峰值与官方通报整合为概览，数值与 Kp 同行，日期和带 UTC 的时间成组换行。趋势图缩短上下留白并增大轴标签。[手机截图](./evidence/mobile-observation-workspace-2026-11-25/utility-environment-390.png)

Edge 在 320、390 和 1440 像素视口验证布局和关键交互。采样空态、空计划和一条关注为专项样例，已有采样方案、观测站和空间环境数据来自本地运行服务。[实测](./evidence/mobile-observation-workspace-2026-11-25/utility-pages-check.json)

## 卫星详情、时间与观测流程复验

2026-11-25。地图点位选择此前只更新卫星编号，搜索面板单独决定是否打开详情。现在地图点位、底部「详情」和搜索结果打开同一张面板。搜索进入后仍可返回搜索。切换目标时使用已知名称，关闭面板复用原地球画布。北斗高轨定位使用明确的向地视角，保留地球参照。观测地图总览优先用连续本地底图，放大后可加载分级在线图层。

实时或回放时间直接显示在探索首页。独立「设置」页存储默认显示时区和探索动画偏好，数据状态与精确回放时间留在当前场景。目录和探索分组改用项目的深色选择器，弹窗内可触控选项。

「设置」统一从应用右上角的齿轮进入，位于用户名与退出按钮之间。三种手机视口和两种桌面视口已验证入口位置及点击跳转。[实测](./evidence/mobile-observation-workspace-2026-11-25/settings-header.json)

探索页的影像、街道和地名选项已迁到「设置 → 探索底图」，刷新后保留。太空菜单移除电影视角和场景说明。观测规划和站点地图可继续就地选择底图。[底图设置](./evidence/mobile-observation-workspace-2026-11-25/settings-basemap-390.png) · [太空菜单](./evidence/mobile-observation-workspace-2026-11-25/space-menu-settings-390.png)

手机「太空」并入地图右上角工具组，选择场景后自动收起。探索页去掉数据状态入口和远景图像来源说明，素材署名归入「设置 → 探索底图 → 素材署名」。回放时仍可点时间进入精确定位。[截图与实测](./evidence/mobile-observation-workspace-2026-11-25/explore-clean-tools-390.png) · [浏览器记录](./evidence/mobile-observation-workspace-2026-11-25/explore-clean-tools.json)

手机主导航改为「探索」「目录」「观测」「更多」同排，当前页用蓝色下划线标记。按钮保留至少 44 像素触控高度，读屏保留完整页面名称。三种手机视口和一种桌面视口验证跳转、活动标记及菜单关闭。[新版截图](./evidence/mobile-observation-workspace-2026-11-25/nav-compact-390.png) · [浏览器记录](./evidence/mobile-observation-workspace-2026-11-25/nav-compact.json)

观测规划用「地图」「条件」「结果」切换视图，条件与结果不再整列排在地图下。结果把回放、保存及可展开的曲线放到所选过境卡片，切换视图保留事件。回放回到地图，控制条紧接地球。

- Edge 触屏模拟 35 次视口检查、7 组交互通过。测试实际三维点位、底部与搜索详情入口、时区设置回到首页、弹窗列表、真实 ISS 预测、曲线与回放回到地图后保留事件。[触屏联调](./evidence/mobile-observation-workspace-2026-11-25/mobile-layout.json)
- 北斗 BEIDOU-3 M2 实际定位同时可见点位与地球。同一视口连续 5 次开关详情无未捕获异常。320×568 检查不产生整页滚动，地图与条件可以切换。iOS Safari 真机未测试。[专项记录](./evidence/mobile-observation-workspace-2026-11-25/beidou-and-narrow.json)
- 三种桌面尺寸共 24 次路由几何对照及生产构建通过。[桌面对照](./evidence/mobile-observation-workspace-2026-11-25/desktop-layout.json)
