# 星枢 · 全球卫星态势与观测平台

已实现功能说明 · 2026-11-21

## 系统简介

星枢是一套基于公开轨道数据的卫星可视化与观测规划平台。用户可以在三维地球上查找和跟踪卫星，查看当前推算位置，设置观测站并预测过境，也可以按自定义时间范围生成轨迹、回放结果和保存观测计划。系统覆盖国际空间站、天宫、北斗、GPS、伽利略、GLONASS、星链等公开目录对象。

## 已实现功能

| 模块 | 用户可以做什么 |
| --- | --- |
| 卫星探索 | 旋转和缩放三维地球，切换影像和街道底图、云层与太空视图。通过卫星列表或地球点位选中卫星，查看轨道、地面投影、经纬度、高度、速度及轨道参数，并定位、持续跟踪或关注。 |
| 实时态势与轨迹回放 | 实时态势跟随当前时刻，可开启全球总览并查看实际绘制数量。轨迹回放显示采样起止时间，支持播放、暂停、拖动、倍速和精确时间定位。探索页默认北京时间（UTC+8），可切换 UTC，浏览器记住时区。 |
| 卫星目录 | 按名称或 NORAD 编号搜索，按目录分组、国家或组织、轨道类型和用途筛选，查看卫星元数据、轨道根数历元与数据质量。缺失字段显示为未知。 |
| 采样管理 | 配置固定或相对时间、采样间隔及卫星列表。在独立选星窗口中按北斗、GPS、伽利略、GLONASS 等预设或直接搜索，支持跨组混选。方案可试算、保存、编辑、删除、导出轨迹 JSON，或加载到探索页回放。 |
| 观测规划 | 在地图选点或输入经纬度与海拔，创建观测站并设置默认站。选择单颗卫星或一个分组批次，设置预测范围和最低仰角，查看进出时间、最高仰角、方位、时长、仰角曲线和潜在目视窗口。支持单星过境回放和整组回放。 |
| 空间环境 | 查看地磁 Kp 指数、24／72 小时观测趋势、地磁活动预报和公开通报。可按类别、来源和日期筛选事件，查看原始来源及对导航、通信的一般性影响。数据缺失或过期时会提示。 |
| 态势大屏 | 全屏查看三维地球、公开目录规模、轨道分布、国家或组织及用途占比、近 12 个月发射卫星数量趋势。动态榜单可切换最新根数或所选观测站已计算的未来过境。 |
| 我的空间与通知 | 注册登录后管理个人关注、观测站、历史计算和观测计划。过境计划可保存、回放、取消或确认重算。支持提前 5、10、30 分钟的站内提醒，以及单条或全部标记已读。 |
| 系统管理 | 管理员可查看数据源状态、最后成功与下次调度时间、采集日志和任务详情，发起手动采集，启用或停用用户，并查看审计记录。支持演示外部数据源故障和检查恢复结果。 |

## 数据口径与使用范围

- **实时位置是轨道推算。** 系统定时采集 CelesTrak 公开轨道根数，用 SGP4 计算指定时刻的位置。画面时刻、根数历元和最近成功采集时间可以分别查看。全球总览覆盖当前附近的短时间窗口，较长时段的轨迹在回放模式查看。
- **采样与观测预测各有用途。** 采样管理用于生成自定义轨迹，单方案支持最多 12 颗卫星、24 小时和 12,000 个点。观测规划用于判断卫星何时经过指定站点，分组预测和整组回放每个批次最多 500 颗。潜在目视窗口依据仰角、地面太阳高度和卫星受光计算，实际观测还受天气、亮度和遮挡影响。
- **计划与采样方案的数据保存方式不同。** 已保存的观测计划带计算依据，可按该依据回放。采样方案保存卫星和时间等参数，再次加载时按目录中当时可用的根数计算。导出的 JSON 可留存当次轨迹结果。
- **外部来源异常时保留状态。** 采集失败可保留最近有效数据，并显示来源和时效。空间天气已验收 NOAA 与 GFZ 来源，NASA DONKI 补充来源尚未通过本机接入验证。近地高清底图细节依赖在线图源。

## 答辩演示流程

1. 登录后打开「卫星探索」，开启全球总览，搜索 ISS，展示定位、持续跟踪和轨迹回放。
2. 在「采样管理」加载演示账号的「ISS 与天宫两小时」方案，展示多星回放、时区切换和轨迹导出。
3. 在「观测规划」选北京观测站，打开 ISS 过境结果，展示仰角曲线、地面轨迹和观测计划保存。也可从历史计算打开 ISS 与天宫的整组回放。
4. 切到「态势大屏」，介绍卫星分类统计和过境榜单。使用管理员账号可展示采集状态和运行日志。
