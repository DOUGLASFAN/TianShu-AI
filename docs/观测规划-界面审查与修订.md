# 观测规划界面审查与修订

日期：2026-11-15。依据为用户提供的四张实际截图，以及已有视觉、交互规范。范围为阶段 5 页面、观测站弹窗和探索页“预测过境”入口，没有启动阶段 6。

## 问题与原因

| 问题 | 原因 | 本次处理 |
| --- | --- | --- |
| 新建站点弹窗贴住左上角 | Tailwind Preflight 清除了原生 dialog 的默认外边距，弹窗样式没有显式恢复居中 | 固定定位、四边 inset、margin auto；限制宽高，内部可滚动；1920／1440／390 实测 |
| 下拉选项出现灰白系统菜单 | 原生 select 的展开菜单由操作系统绘制，无法仅靠输入框 CSS 统一 | 站点、时区、排序使用统一深色组合框；支持方向键、Enter、Esc、Tab、点击外部关闭，保持焦点 |
| 没有站点时只有占位选项 | 空列表被当作普通可选下拉框呈现，主要行动仅藏在加号内 | 改为明确的“新建观测站”入口；有站点时再显示选择与管理控件 |
| 三种时间范围仍需展开选择 | 固定三个互斥选项使用了较重的菜单交互 | 改为“24 小时／3 天／7 天”分段按钮，选中状态直接可见 |
| 探索页新增按钮撑满详情侧栏 | Link 的独立样式没有沿用详情按钮的左右内边距 | 与关注按钮共用边缘尺寸；保持次级蓝色强调和相同圆角 |
| 大块空详情卡与零结果区域 | 无事件时仍渲染完整高度的详情容器，叠加全页宽度限制 | 无事件不显示详情卡；减少空结果区高度；观测页面采用更合理的可用宽度 |
| 小地球被放入横向大框 | 默认全球远景没有结合观测站任务设置相机 | 默认站点区域近景，补充“查看全球／定位观测站”实际操作；历史结果仍显示对应站点快照 |
| 仰角曲线藏在全部列表之后 | 详情内容按实现顺序堆叠 | 曲线和目视子窗口放到结果列表前；缩短表格行高和过量间距 |
| 弹窗打开后背景还可滚动 | 缺少模态期间的背景滚动锁定 | 打开时锁定，关闭时恢复；名称输入初始聚焦，保留键盘关闭与返回焦点 |
| 默认开始时间放久后过时 | 输入值只在页面首次挂载时取当前时间 | 当前时间模式定期更新，提交取实际当前时刻；手工编辑和历史查询保持指定时间，结果完成后冻结条件 |

上轮验收覆盖了主要功能，但没有验证弹窗的屏幕位置、原生菜单展开态和空页面比例。本次曾取消 S05-01／S05-07 的完成勾选，修复并复验后恢复，保留已有算法和数据测试证据。

## 视觉与交互约定

延用深蓝黑、青蓝操作和琥珀选中态。保留简洁中文，必要字段有标签和单位，不增加口号、装饰性英文或填空式介绍。菜单、边框、圆角、按钮高度与页面密度统一。

站点编辑直接显示真实可交互地图，点选仍是独立模式；取消不保存候选点。默认站必须在切换到其他站点后才可替换，不提供界面可取消而服务仍强制保留的假操作。

当前地球预览是公开静态贴图和计算轨迹；三维通用卫星素材仍遵循此前用户接受的示意模型约定。来源、算法和数据质量保留在可展开区域。未改变几何过境或潜在目视的定义。

## 第二轮细调：弹窗尺寸、按钮分组与页面切换

2026-11-15 根据用户进一步反馈调整：

- 桌面新建观测站从 840 px 扩至 1120 px，大屏为 1200 px；地图从 246 px 高提升至 360／420 px，并扩大输入框和表单间距。小屏仍限制在视口内，内容可滚动。
- 探索详情的四个动作改为两行：定位／跟踪，预测／关注；组间分隔和留白统一，移除独立按钮遗留的外边距。
- 删除探索、观测页面覆盖公共导航栏高度、字号和间距的规则。所有业务页共用桌面 64 px 导航栏及同一组响应式规则，固定滚动条槽位；页面内容只做短暂透明度过渡，不缩放导航或整页。
- 弹窗使用视口中心定位，避免固定滚动条槽位后出现半个滚动条宽度的视觉偏移。

复查脚本：`frontend/verify-shell-layout.mjs`。证据记录在 [导航与弹窗检查](./evidence/shell-layout-2026-11-15.json)，同时复跑原 UI 专项与生产构建。截图：[大屏弹窗](./evidence/shell-dialog-1920-2026-11-15.png)、[按钮分组](./evidence/shell-actions-2026-11-15.png)。

第二轮验证结果：1920／1440／390 宽度下弹窗分别为 1200／1120／366 px，均在视口内；三种宽度合计 15 次跨页比较中，顶栏、品牌和导航项的位置／尺寸与字号一致。两行操作布局、原 7 组 UI 流程及最终生产构建通过。
