# 星枢 · 阶段 2 接口与数据库说明

2026-11-12｜API v0.2.0。正式服务 `backend.app.main`，本地端口 8001；阶段 1 的 `backend.phase1.server` 为独立验证服务，不与正式业务 API 混用。

## 1. 工程与职责

```text
frontend/                  React + TypeScript 独立工程
backend/app/api/            HTTP 路由、输入校验与权限依赖
backend/app/core/           配置、密码/JWT/会话与缓存
backend/app/services/       采集校验与原子数据更新
backend/app/models.py       数据模型与约束
backend/alembic/            版本化迁移
backend/worker.py           独立一次性采集进程
backend/phase1/             已验证轨道计算能力，后续业务可复用
infra/                     容器构建与反向代理配置
scripts/                   初始化、启动与验收脚本
```

业务计算和第三方请求放后端。前端只访问同源 `/api/*`，开发时由 Vite 转发到 8001；容器配置由 Nginx 转发。没有把第三方密钥、数据库口令或 JWT 签名密钥嵌入前端。

## 2. 请求与响应约定

- 受保护接口使用 `Authorization: Bearer <token>`。未登录/无效会话 401，普通用户访问管理功能 403，私人资源不存在或非本人统一 404。
- 所有响应有 `X-Request-ID`，请求可传入 1～64 位安全字符 ID；错误正文也返回同一 `requestId`。
- 单个业务资源返回 `{ data: ... }`，分页返回 `{ total, list, page, size }`；只有有意义的数据来源/缓存/单位说明放 `meta`，不是所有资源都有来源字段。
- 错误为 `{ error: { code, message, fields }, requestId }`。校验错误不回显原始输入，避免密码出现在错误响应中；未知异常不返回 SQL、连接串和堆栈。
- 持久化日期为带时区 UTC，JSON 用 ISO 8601。轨道角度为 °、高度 km、速度 km/s；站点海拔 m。根数历元与采集时间独立保存。
- 标准分页 page≥1、1≤size≤100；查询无结果返回 total=0 与空 list。

错误示例：

```json
{"error":{"code":"AUTH_REQUIRED","message":"请先登录","fields":[]},"requestId":"example-request-id"}
```

## 3. 认证与会话

注册仅接受 username/password，额外 role、user_id 等输入被拒绝。用户名小写规范化、唯一，密码至少 10 字符，Argon2id 哈希；数据库不保存明文密码。

JWT 使用固定 HS256、受保护随机密钥、sub/jti/版本、iat/exp、issuer/audience。每次业务请求同时检查用户状态、token_version 和数据库会话，防止仅靠自包含 Token 导致退出/禁用后继续访问。

访问 Token 只放浏览器内存。登录另写 HttpOnly、SameSite=Strict 的会话 Cookie；刷新页面通过 `POST /api/auth/session` 恢复内存 Token，此入口要求允许的 Origin。普通业务不靠 Cookie 鉴权。退出撤销数据库会话、删除 Cookie；禁用用户撤销其会话并提升版本，重新启用不复活旧 Token。

本地 HTTP 下 Cookie 的 Secure=false；HTTPS 部署需配置 true。会话期限初版 8 小时，恢复不延长期限。Redis 登录频率限制以 IP/用户名的哈希键计数，不保存明文密码；缓存异常仍可进行数据库会话验证。

## 5. 数据模型与迁移

首版 10 张业务表，另有 Alembic 版本表：

| 表 | 主键/主要关系 | 索引与约束 |
| --- | --- | --- |
| users | UUID | 用户名唯一索引，role 检查 |
| auth_sessions | UUID → users | user_id、expires_at，撤销状态 |
| satellites | NORAD 整数 | 名称、归属、历元；当前根数/元数据/来源 |
| satellite_groups | slug | 分组名称 |
| satellite_group_members | group+NORAD → 分组/卫星 | 联合主键，NORAD 索引 |
| data_sources | 来源 ID | 公开 URL、最后成功时间 |
| collection_runs | UUID → 来源 | 状态、来源、开始时间索引 |
| orbit_elements | UUID → 卫星/采集记录 | NORAD+内容哈希唯一，NORAD+历元索引 |
| favorites | user+NORAD → 用户/卫星 | 联合主键去重 |
| observation_stations | UUID → 用户 | 用户索引，经纬度检查 |

迁移版本 `bcb88636134b`。初次 `alembic upgrade head` 实际应用于本机 PostgreSQL；再次初始化不清库、不重置账号。`alembic check` 确认模型与迁移无未记录差异。生成的 downgrade 脚本保留，但没有对用户正式数据库执行降级。

运行角色 `xingxu_app` 为非超级用户、无创建数据库/角色权限；仅拥有项目数据库。管理员初始化角色只供本地初始化工具使用，不由 API 连接使用。

## 6. 采集、历史与缓存

初次导入复用阶段 1 有来源、时间和哈希的真实目录快照，日志标记 snapshot_seed；已有记录不在每次启动时重导。新环境没有全目录缓存时使用仓库的 3 颗真实代表样本，界面计数如实显示，后续可刷新取得目录。

采集先校验完整候选集，再在单个 PostgreSQL 事务中更新当前卫星、根数历史、分组与成功状态，使用数据库 advisory 事务锁串行化数据替换。坏批次不覆盖有效目录，失败记录独立提交，只存错误代码。相同 NORAD/原文哈希不重复新增历史。

详情缓存放 Redis，2 小时 TTL；键包含轨道及元数据版本哈希，避免元数据变更后拿到旧详情。每次先检查当前数据库版本和质量，Redis 不可用回退数据库。搜索和分页直接查询本地数据库，不向上游发请求。

上游数据获取复用来源验证脚本的 TTL、HTTPS 校验和错误停止规则。日常读取根数有明确历元/年龄/质量，不把接口连接成功等同于根数新鲜。

## 7. 运行条件与边界

当前本机实际运行 PostgreSQL 17.11（EDB Windows 二进制）及 Redis 8.10.3（redis-windows 社区构建），程序与数据位于 D 盘项目，未注册 Windows 服务、未安装 WSL、未更改系统默认 Python。原生 Redis 不是官方 Windows 分发，来源、发布摘要与校验值保留。

`compose.yaml` 提供 PostgreSQL/Redis 官方 Linux 镜像、API 和 Nginx 前端。与原生目录分开使用 `.local/data/compose/`，不能将 Windows PG 数据目录直接交给 Linux 容器。当前无 Docker 运行时，**Compose 仅做结构检查，未运行容器**；不能据此声称 Docker 部署已验收。实际运行验收依据为原生真实服务与本机启动脚本。

三维正式探索、高清材质、轨道动画、完整空间天气/预测/计划/通知等仍按后续阶段交付。当前目录工作台不是 A 方案的最终三维首页。
