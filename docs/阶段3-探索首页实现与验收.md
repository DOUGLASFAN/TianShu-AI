# 星枢 · 阶段 3 探索首页实现与验收

日期：2026-11-12。状态：S03-01～S03-08 全部通过，阶段 3 完成；逐项状态以[阶段验收清单](./阶段验收清单.md)为准。

## 设计依据与交付

已将用户同意的 NASA Eyes、KeepTrack、Earth Nullschool 等参考写入[参考网站与实现决策](./阶段3-参考网站与实现决策.md)，并补充到视觉规范和交互原型。第三方公开截图与星枢实际截图分开保存，未把生成效果图或第三方界面作为本项目运行成果。

正式 `/explore` 页面采用顶栏、卫星目录、地球安全区、卫星详情和底部时钟五个区域。保留阶段 2 的目录表格 `/catalog`、我的空间和管理入口。目录关键字、分组、页码及选中卫星写入 URL；切到其他页面再通过导航返回时保留探索上下文。

地球是 Cesium 1.147.0 实际渲染的 WGS84 椭球，日间地表、夜光与云层使用本地 8192×4096 素材。自定义地球材质根据太阳方向混合昼夜，地球可旋转、缩放，可切换云层和纯净视图。素材来自 Solar System Scope / INOVE，CC BY 4.0，保留界面署名及[来源和 SHA-256](../assets/earth/manifest.json)。这些是历史合成可视化资源，不能当作实时云图或定量夜光数据。

三维场景与轨迹均不依赖外部瓦片请求。Cesium 和探索页面延迟加载，登录页无需先下载三维引擎；构建包含完整本地运行资源，新增图像原件约 19.3 MB。

## 数据与采样契约

| 接口 | 行为 |
| --- | --- |
| `GET /api/explore/scene` | 受保护，读取数据库内代表对象；最多 24 个候选，当前可用 20 颗，每颗 241 个采样点。明确不是全量目录绘制，失败对象单列。 |
| `GET /api/explore/satellites/{id}/trajectory?at=...` | 受保护，读取所选卫星真实根数，生成覆盖中心时刻的有界轨迹；时间必须有时区且在当前前后 7 天内。 |
| 既有目录、详情、关注接口 | 搜索、分组、分页、元数据、根数历元、采集时间和私人关注均从正式 API 返回。 |

后端使用阶段 1 已核验的 SGP4/Skyfield，并返回 ITRS/ECEF 米坐标与 km/s 速度。采样格式为 `[相对起点秒数,x,y,z,速度]`，包含根数内容哈希、起止时间、步长和来源质量。场景为两小时窗口、30 秒间隔；选星轨迹为 120～1500 分钟有界弧段，按周期选择 20/60/120 秒步长，超长周期会明确说明有限弧段。

Redis 按卫星、根数哈希、采样时间、窗口和步长缓存 300 秒。质量年龄在返回时重新计算。传播失败返回明确错误码，不写入无效采样，也不修改有效数据库根数。

前端由 Cesium `SampledPositionProperty` 线性插值并关闭双向外推，连续运动不由 React 每帧状态更新驱动。右侧推算参数按约一秒节流更新。空间轨迹以地固坐标呈现，蓝色虚线为地面投影，图例明确区分；不是固定惯性系闭合轨道示意图。

## 已实现的交互

- 300 ms 搜索防抖、Enter 提交、清空、分组与分页；请求取消和查询键隔离旧响应，空结果有恢复提示。
- 列表与三维点位选择卫星；所选详情和轨迹隔离，切星取消旧飞行并移除旧高亮轨迹。
- 定位与持续跟踪分别操作。拖动退出锁定并说明，全球视角恢复默认相机，纯净视图可随时恢复面板。
- 关注以服务端成功为准，重复点击受忙碌状态保护，复用阶段 2 的数据库归属与去重约束。
- 当前时刻、暂停查看、时间推演与采样结束分开显示；1/10/30/60 倍速、时间轴、Home/End、精确 UTC 输入、回到当前及刷新采样可用。
- 超出有效采样时停止显示位置并禁用定位/跟踪；不无限外推，也不把推演标成实时遥测。
- 加载、无结果、失败、陈旧根数、传播失败和无位置分别反馈；提供对应重试入口。
- 没有阻塞操作的长开场。面板短入场和相机过渡可中断，遵循系统减少动态效果，也有应用级选择。
- 切页清理 Cesium Viewer、事件、采样实体和回调；初始化失败也释放已创建的 Viewer。

## 验证与限制

后端已在独立真实 PostgreSQL 测试库和 Redis DB 15 完成 8 项检查，包含鉴权、代表场景、LEO/MEO/GEO 轨迹、坐标参考复核、版本缓存、非法时间、缺失对象及传播失败不缓存。见[JUnit](./evidence/phase3-backend-2026-11-12.xml)、[隔离环境记录](./evidence/phase3-test-environment-2026-11-12.json)。阶段 1 的 14 项计算与解析回归再次通过。

最终 11 组浏览器检查全部通过；三次切页重建 created=4、destroyed=3、active=1，无页面运行时异常或 API 5xx，外部 HTTP 请求数为 0。既有阶段 2 的 20 项后端回归再次通过。构建、3 张地球原件/公开资源/生产资源 SHA-256 对照及已知口令密钥扫描通过，见[汇总记录](./evidence/phase3-acceptance-2026-11-12.json)。

最终浏览器结果见[验证记录](./evidence/phase3-browser-2026-11-12.json)，脚本为 `frontend/verify-phase3.mjs`。浏览器采用隔离 Edge 软件 WebGL，并在冷加载前阻断外部 HTTP；该方式用于功能、布局和资源释放验证，不代表用户 GPU 的实际帧率。1440×900、1920×1080、2560×1440 的截图为实际页面。

迭代时发现并修复键盘 End 定位与快速输入被旧查询覆盖问题；另外修正故障注入场景，让它使用新的采样版本，避免有效缓存命中绕过预期的失败请求。同时修复了 Fabric 缓存 DOM 图片对象导致 Viewer 重建失败的问题，改用可复用的 URL 材质参数；系统动态偏好通过显式媒体查询监听同步。前期失败记录保留，不以早期失败结果当作最终验收。

完整的全球万颗点渲染、后台定时采集、WS 重连、自动滚动采样、预测、观测计划与提醒仍属于后续阶段。当前采用显式刷新采样，达到范围末端停止；未宣称全天无缝实时服务。8K 合成贴图也不是近地高精度瓦片或地形。

## 复查方式

```powershell
# 项目根目录
./scripts/start.ps1
backend/.venv/Scripts/python.exe scripts/verify_phase2_backend.py --stage 3
npm run build --prefix frontend

# 单独在 frontend 目录执行浏览器检查
node verify-phase3.mjs
```

数据库/Redis 重启验证不得与上述依赖它们的测试并发。首次资源准备仍需 `npm run prepare-assets --prefix frontend`。Compose 容器运行尚未验证，本阶段不改变这一边界。
