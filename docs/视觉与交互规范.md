## 1. 设计定位与参考优先级

2026-11-25 用户确认「星巡 + Logo A」。页面顶栏、登录、大屏和标签图标共用矢量标记。采样管理标题与卫星目录共用字号规则，手机 24 像素、桌面 30 像素，手机表单输入保持 16 像素。[确认版标记](../frontend/public/branding/xingxun-mark.svg) · [手机实测](./evidence/mobile-observation-workspace-2026-11-25/xingxun-sampling-390.png)

普通业务页复用 Motion 做 170 毫秒的淡入和短位移，观测页采用淡入。选择菜单按实际展开方向短距离入场，采样选星窗单独过渡。减少动态效果时跳过这些过渡，地图回放切换复用原画布。[Motion 无障碍指南](https://motion.dev/docs/react-accessibility) · [Radix Primitives 动画指南](https://www.radix-ui.com/primitives/docs/guides/animation) · [验证记录](./evidence/mobile-observation-workspace-2026-11-25/xingxun-brand-and-motion.json)

2026-11-25 交互动效修订。按钮按压轻缩，主导航下划线、探索模式与观测视图的选中指示采用短程滑动。页面入场采用轻淡入，地图保持位置，常用页面在指针接近或键盘聚焦时预加载模块。系统减少动态效果下切换直接显示最终状态。[实测](./evidence/mobile-observation-workspace-2026-11-25/interaction-motion.json)

2026-11-19 星空资源试用修订：复用 NASA 星图与成片动画，替代前版 ESO 1024px 背景；背景和电影入口明确区分。电影采用居中原生播放器，保留 4K、来源署名及非实时说明，减少动态效果时不自动播放，退出恢复原三维画面。摄影／星表资源仅作技术转换，不自行生成银河内容。[试用验收](./高清星空与电影视角试用验收.md)。

2026-11-18 太空远景：探索页仅新增“太空”入口，提供银河开关、地月全景、月球近景、太阳系示意、返回地球；行星可点击近看。银河使用本地摄影天空盒，保持完整可见署名；地表附近隐藏。太阳系明确标识距离／尺寸已调整，并隐藏不适用的卫星轨迹图例；移动端将尺度说明移到工具下方，避免覆盖入口。镜头飞行尊重减少动态效果，飞行期间不按高度误切模式。天空盒转换按小块让出主线程，避免一次性长计算阻塞交互。大屏默认保持原有地球风格。[说明与验收](./地图加速与太空场景验收.md)。

2026-11-18 系统提示修订：历史恢复检查失败不常驻跨页横幅，结果与重新检查保留在管理中心。只有演示运行中／恢复检查中显示全局提示；可关闭当前恢复提示，运行中的故障演示可收起为小标记，仍能展开。同轮关闭状态在会话刷新、轮询与切页后保持，新一轮演示必须重新提示。不删除失败记录或将其改为正常。[验证](./evidence/status-dismiss-2026-11-18.json)。

2026-11-15 地图增强：远景保留合成地球，缩近时材质连续渐隐并露出分级影像。地图左上保留单个“底图”入口，展开后切换影像／街道与地名；街道底图内置地名，开关禁用并明确说明。避免与顶部故障状态栏、选点提示重叠；在线内容的署名保留常显。失败保留已有图像和本地地球，不以空白或无限加载替代错误状态。来源精度、网络与离线边界见[分级底图说明](./分级底图与近地浏览.md)。

### 界面文案约定（2026-11-12 用户修订）

2026-11-15 用户进一步指定：模型预览进入页面后默认缓慢自转，保留暂停/继续按钮；系统或应用减少动态效果启用时静止。此约定取代此前模型“默认静止”的设置。[验证记录](./evidence/model-default-rotation-2026-11-15.json)。

2026-11-15 右侧详情顶部改用真实 GLB 三维预览，替代装饰性圆形图标。模型展示区独立于地球，支持拖动、缩放、方向键和重置，不默认持续自转；名称、编号和数据状态置于模型下方，不新增装饰标签。通用示意属性与 NASA 作者署名收纳于“数据来源”。

2026-11-15 补充：默认界面避免不必要的辅助标签与说明，让布局承担解释。探索画面不再重复显示中央场景标题和“卫星详情”栏名，以实际卫星名称作为详情标题；目录数量与目录标题放在同一行。取消重复统计卡、页面介绍短句、角色徽章和通用说明页脚。来源、图像署名、采样规则与时效信息按需展开；表单标签、单位、图例、时间模式、错误及陈旧数据提示保留。该规则适用于后续页面，不能重新用宣传文案填补留白。

验证：[页面检查](./evidence/minimal-interface-2026-11-15.json)、[实际探索页](./evidence/minimal-explore-1440x900-2026-11-15.png)。

- 页面标题直接说明功能，例如“地球与轨道”“卫星详情”“数据来源”，不使用“从地球，望向轨道”等口号或诗意短句。
- 默认采用中文界面，删除装饰性英文眉题、重复的中英文标题及英文品牌副标题。无需用另一句中文填满删去的空间。
- 登录、目录、我的空间和管理页面采用相同规则。操作用“关注卫星”“定位”“持续跟踪”等明确动词，不使用“开启你的探索”等宣传表述。
- 保留原始卫星名称、NORAD 编号、UTC、必要单位，以及 Cesium、CelesTrak 等技术/数据来源和合法素材署名；不随意翻译专有名称。
- 本次已在五个实际页面检查，构建通过。[检查记录](./evidence/copy-review-2026-11-12.json)、[修改后探索页](./evidence/copy-explore-2026-11-12.png)。该文案约定优先于早期概念图中的宣传用语。

2026-11-12 补充：已确认采用 NASA Eyes 的地球与空间层次、KeepTrack 的选星/详情/跟踪关系、Earth Nullschool 的留白与克制动态。具体借鉴、访问验证边界和浏览器验收门槛见[阶段 3 参考网站与实现决策](./阶段3-参考网站与实现决策.md)。该记录是实现依据，不代表视觉已通过运行验收。

面向课程展示与个人探索的写实航天工作台。选定 A 方案：真实地球为视觉核心，深蓝黑背景、轻玻璃侧栏、青蓝操作强调、琥珀色选中轨道。六个业务页面共用相同组件语言。

优先级：产品需求中的计算与状态语义 → 本文可读性和交互规则 → 交互原型 → 生成效果图。图片中与文字规则冲突的内容不进入实现。

主参考：[A 探索首页](./design-concepts/A-cinematic-aerospace.png)。新增参考：[A 观测规划](./design-concepts/A-observation-planning-v1.png)。登录背景：[装饰性地球背景](../assets/branding/auth-orbit-background-v1.png)。

生成图片仅帮助理解布局和氛围。不得把整张效果图作为网页背景伪装可操作界面；地球、轨迹、图表、文字、图标均独立实现。

### 1.1 保留与校正

- 保留：地球真实光照、薄大气层、深色面板、清晰分栏、细轨道与小范围选中光晕。
- 校正：地球不必始终占满屏幕，选中目标不得被侧栏遮住；业务名称和状态依据实际数据。
- 卫星列表不默认使用生成的“真实卫星照片”；采用统一矢量类别图标，照片只在有来源时展示。
- 参考图中的“亮度良好”“可观测”等断言改成“卫星受光”“几何过境/潜在目视窗口”；首版没有准确视星等依据。
- 参考图日期、编号、仰角、轨迹和昼夜分界均是示例，不作为算法结果或地理贴图。
- 首版只设计深色主题；浅色概念图不是当前主题交付要求。

## 2. 设计变量

组件通过语义 Token 使用颜色、间距和时长，禁止各页随意定义相似色。下列数值是首版基线，在真实合成画面上验证后可全局调整。

### 2.1 色彩

| Token | 值 | 用途 |
| --- | --- | --- |
| color.bg.canvas | #050B14 | 应用最底层、地球背后的空间 |
| color.bg.shell | #09121E | 顶栏、侧栏外壳 |
| color.surface.base | #0E1927 | 标准不透明内容面 |
| color.surface.raised | #152335 | 菜单、弹窗、输入框悬停 |
| color.surface.glass | rgba(14,25,39,0.94) | 地球上的浮动面板 |
| color.surface.selected | #17354C | 列表及标签选中面 |
| color.border.subtle | #293B4C | 非交互分隔，不承担唯一识别作用 |
| color.border.control | #71869C | 输入与独立按钮可识别边界 |
| color.text.primary | #F2F6FA | 标题、正文、主要数值 |
| color.text.secondary | #B4C3D2 | 标签、次级信息 |
| color.text.muted | #91A4B8 | 时间、单位、来源等仍需可读信息 |
| color.action.primary | #69C5FF | 主要按钮、焦点、链接 |
| color.action.hover | #91D5FF | 主按钮悬停 |
| color.action.pressed | #49AFE9 | 主按钮按下 |
| color.action.on-primary | #06101C | 亮蓝按钮文字，避免浅蓝底白字低对比 |
| color.status.success | #60D6AC | 已保存、连接可用等成功状态 |
| color.status.warning | #FFC56B | 陈旧、时间推演、待处理提示 |
| color.status.danger | #FF919A | 失败、不可用、危险操作 |
| color.orbit.default | #78B8E8 | 普通轨道 |
| color.orbit.selected | #FFC56B | 当前选中轨道与事件 |

在不透明 #0E1927 底上，主文字/次文字/弱文字静态对比度计算约为 16.29/9.84/6.91；亮蓝按钮深色字约 10.04。这里只验证静态配对，不代表透明面板、贴图合成、所有状态已完成可访问性验证。

文字普通尺寸目标对比度至少 4.5:1；大字和有意义的非文本标识目标至少 3:1。透明面板在明亮云层背景上仍须测量，不够时增加底色不透明度；不靠更强模糊解决。

成功、警告、失败均用“图标 + 文字”，不能仅用红绿圆点。普通轨道颜色不表达卫星威胁等级。

### 2.2 字体与数据排版

- 中文优先本地 Noto Sans SC，回退 Microsoft YaHei、系统 sans-serif；获取合法字体文件并保留许可，准备完成前使用系统回退。
- 英文沿用同一无衬线体系；时间、编号、数值使用本地 JetBrains Mono 或系统 monospace，启用 tabular-nums。
- 不运行时拉取远程字体；不让字体加载阻塞界面。

| 角色 | 字号/行高 | 字重 | 用途 |
| --- | --- | --- | --- |
| display.metric | 32/40 | 600 | 大屏主要数值 |
| title.page | 24/32 | 600 | 普通页面标题 |
| title.panel | 18/26 | 600 | 栏与弹窗标题 |
| title.item | 16/24 | 500 | 卫星名称、条目标题 |
| body | 14/22 | 400 | 工作台正文、表格 |
| body.comfortable | 16/24 | 400 | 表单与说明长文 |
| caption | 12/18 | 400 | 辅助说明、轴标签 |

正文不小于 14px，辅助信息不小于 12px；大屏展示正文按距离优先 16px。中文不加夸张字间距，不全站大写。单位与数值留适当间隔；时间展示包含日期和时区上下文，跨日明确写“次日”。未知显示“未知”或“—”并可解释，不显示 0 代替缺失。

### 2.3 尺寸、材质与层级

- 间距阶梯：4、8、12、16、20、24、32、48px。面板内边距 20px，紧凑区域 16px，主区块间距 16/24px。
- 圆角：小标识 4px，按钮/输入 8px，面板 12px，弹窗 16px；药丸只用于短筛选分段和状态标签。
- 面板 1px 细边框；默认 blur 12px，最多用于地球覆盖层，不在每个列表项叠加模糊。
- 阴影：浮层参考 0 16px 48px rgba(0,0,0,.28)，对话框参考 0 24px 80px rgba(0,0,0,.42)。不让全部元素发光。
- z-index：地球 0；轨道标签 10；固定面板 20；菜单 40；遮罩 60；对话框 70；通知 80。DOM/Cesium 内部层级由对应容器隔离。
- 控件标准高 44px，紧凑表格行内控件可为 32px；独立图标按钮点击区域 44×44px，视觉图标 18/20/24px。
- 图标统一使用 Phosphor outline 家族，常规字重，禁止混用 emoji。装饰图标 aria-hidden，图标按钮有中文可访问名称。

## 3. 页面栅格与响应式

### 3.1 全局壳

1920×1080：顶栏高 64px，内容外边距 24px；全局导航列出五个业务入口，管理入口放账号菜单，仅管理员可见。通知与账号在右侧，设置收纳在账号菜单。顶栏同时最多一个导航激活态。

工作台采用布局自适应，不对整个 HTML 页面缩放；独立大屏才以 1920×1080 画布等比缩放。地球容器保留独立边界，面板滚动不带动地球缩放。

### 3.2 探索页

- 左栏 304px，右栏 360px，列间距 16px，中央占剩余空间；地球可绘制在全画幅背景，但相机目标按中间安全区定位。
- 顶栏下 24px 开始，底部留 72px 时间工具条与 16px 间距；目录、详情内部独立滚动，工具条不覆盖内容。
- 1440px 档外边距 16px，左 264px、右 320px；2560px 档左右栏上限 336/384px，中央扩展，不无限放大文字。
- 1280px 以下目录转可开合抽屉，右侧详情保留；1024px 以下用单个详情抽屉，保证同一时刻不出现两块互遮挡面板。
- 高度不足或浏览器 200% 缩放时切换纵向文档布局，允许工作台页面滚动，不能为了无滚动条裁掉操作。

### 3.3 观测规划页

左栏 288px 条件，右栏 360px 详情，中间为地球/局部地图（约 55% 高）和结果列表（约 45% 高），底部统一回放条。1440 档左 264、右 320px；小屏详情转抽屉。结果列表有标题和分页，不与整页同时进行同方向多层滚动。

### 3.4 其他页面

- 空间环境：普通文档流，内容最大宽 1600px；概览、观测／预测趋势、事件列表与来源分层。阶段 7 为容纳原文和多种时间，事件详情调整为居中大弹窗，宽度最多 1000px，窄屏保留 12px 边距；关闭恢复原列表与焦点。
- 通知中心：独立 `/notifications`，铃铛显示未读数；列表只区分全部／未读，保留撤销版本与计划链接，自动更新不抢焦点。内容最大宽 1140px。
- 我的空间：内容最大宽 1440px；关注/观测站/计划/通知四个页内标签；表单弹窗宽 480px。
- 管理中心：普通表格与工具栏，宽度上限 1680px；日志详情侧抽屉，不使用大面积玻璃效果。
- 登录：左侧约 58% 装饰图，右侧 420px 表单与安全边距；1024 以下仅保留低对比背景与居中表单。不要把表单画进图片。
- 大屏：64px 顶部、底部 40px 状态，中间按左右统计 + 中央地球布局；保留状态与图例，不在画布上放复杂管理表单。

2026-11-15 阶段 8 落地：独立 `/dashboard` 按 1920×1080 实际容器等比留边，临时取消大屏文档的滚动条槽位，离开恢复工作台布局；地球按视场容纳完整球体。全局故障／恢复提示在大屏占用独立状态行，缩减中部可用高度并重新适配地球，不覆盖指标和图表。榜单支持按钮、悬停和键盘聚焦暂停；管理页采用来源卡片、任务／采集记录表、右侧详情抽屉，窄屏只在表格内部横向滚动。

移动端首版保证登录、列表、表单与文本结果基本可读可用；不承诺完整桌面三维体验，也不显示一个遮挡全页且无法关闭的“不支持”提示。

## 4. 组件规范

| 组件 | 默认/交互状态 | 规则 |
| --- | --- | --- |
| 主按钮 | 默认、hover、pressed、focus、loading、disabled | 每个任务区一个主操作；加载保留原宽度和“保存中…”标签 |
| 次按钮 | 透明深底、控制边框 | 跟踪与定位分开；危险操作不用主蓝色 |
| 文本按钮 | 蓝色文字、hover 下划线 | 用于查看来源和次级动作，不伪装成正文 |
| 输入框 | 可见 label、边界、聚焦环、错误说明 | placeholder 不代替标签，输入错误保留值 |
| 搜索框 | 输入/清除/加载/无结果 | 300ms 防抖；Enter 立即提交；新查询取消或忽略旧请求 |
| 分段选择 | 单选、键盘左右选择 | 用于时间范围与少量分组；更多分组进入筛选菜单 |
| 筛选标签 | 已选、可移除、清空全部 | 超出容器换行或“更多 n 项”展开，不缩成不可读文字 |
| 卫星行 | hover、选中、关注按钮忙碌 | 行高默认 64px，至少名称与编号；关注是独立按钮，不嵌套按钮 |
| 表格 | 加载、空、失败、排序、分页 | 排序有文字/图标反馈；不要把整行和操作按钮触发混淆 |
| 详情面板 | 无选择、加载、可用、部分缺失、失败 | 切换对象先更新标题与加载态，不让旧数据冒充新对象 |
| 状态标识 | 图标、文字、详情入口 | 连接状态、数据质量、时间模式分别表达 |
| Tooltip | hover/focus 触发 | 延迟约 400ms，不能放唯一重要说明；Escape 关闭 |
| Toast | 成功/瞬时反馈 | 右上、最多 3 条，约 4 秒；错误与关键降级长期保留在上下文 |
| Dialog | 遮罩、标题、正文、操作 | 初始聚焦合理控件、焦点约束、Escape、关闭后回原按钮 |
| Drawer | 详情与筛选 | 不与同用途抽屉层层叠加，窄屏有独立关闭按钮 |

表单提交失败时：字段旁说明原因，多字段错误提供可聚焦的摘要；服务器错误保留输入和重试入口。成功保存后显示实际返回状态，不能只在点击时显示成功。

删除有后果的站点、取消计划、禁用用户使用确认弹窗，说明影响；关注取消等可恢复动作直接执行。演示账号不自动填入真实用户私人数据。

## 5. 三维、轨道与时间可视化

- 真实地球使用 Cesium 与有来源地理资源，地形首版可不加载高精度地形；AI 登录背景不作为球面贴图。
- 地球大气光晕应在明暗背景均克制，保持地表可辨。恒星静态或极轻微变化，不持续放射状飞行。
- 普通卫星点视觉半径参考 2～3px，选中点 6px、外圈 12px；额外扩大拾取范围并用列表提供精确选择。
- 可见标签优先选中与少量关注目标，普通点不全量显示编号。标签避让左右面板，并在地球背面正确隐藏。
- 普通轨道约 1px，选中约 2px；屏幕线宽与缩放、像素比一起验证。空间轨道、地面投影与未来采样范围有图例说明。
- 琥珀只强调当前对象/窗口，不用于暗示危险。地球遮挡、地面投影与轨迹跨日期线均需真实处理。
- 跟踪状态显示对象名与“退出跟踪”；拖拽触发解除锁定并提示，选中目标仍保留。
- 时间模式固定显示：当前时刻、暂停查看、时间推演；暂停或非当前时间不得仍只标“实时”。
- 轨道推算、ISS 外部位置、演示快照分别标识。WebSocket 连接绿色不等于数据源新鲜。

## 6. 图表规范

- 默认序列依次 #78B8E8、#FFC56B、#A89BE8、#60D6AC、#D6A3BE；类别在全部页面映射一致，未知使用 #91A4B8。
- 轴线与网格弱化，轴标签至少 12px，显示单位、来源时间与统计范围。
- 占比图必须配类别、数量与比例，未知项不隐藏；国家/用途用条形图优先，避免类别太多的小扇区。
- 仰角图纵轴为 °、横轴为指定时区时间；潜在目视窗口用半透明琥珀区间+文字/图例，不能只靠填充色。
- 曲线游标受统一模拟时钟驱动；拖拽和输入时间都能定位，不强制依赖精细鼠标操作。
- 首次图表进入参考 450ms，增量变化参考 180ms；重复 WS 更新不重播整张图。减少动态效果时立即显示最终态。
- 提供可展开数据表/文字摘要，空数据解释原因，不用一组 0 填满图表。

## 7. 动画规范

| Token/场景 | 建议时长 | 轨迹/反馈 |
| --- | --- | --- |
| motion.instant-feedback | 100～140ms | 颜色/阴影，确认输入已收到 |
| motion.control | 160ms | ease-out，hover/按下与小提示 |
| motion.panel-enter | 280ms | cubic-bezier(.22,1,.36,1)，位移不超过 12px + opacity |
| motion.panel-exit | 180ms | 收敛退出，保留焦点语义 |
| motion.layout | 320ms | 面板布局变化，优先 transform，不逐帧改整个页面尺寸 |
| motion.camera | 800～2000ms | 按距离调整，Cesium 相机控制；快速重选取消旧飞行 |
| motion.intro | 总计不超过 2400ms | 地球就绪后定位、面板 60ms 错峰出现；可跳过 |
| motion.orbit | 250～450ms | 透明度过渡，不改变算法时间 |

原则：交互当下先反馈，动画不锁住按钮；连续操作只保留最后目标，不排队播放过时动画。首页开场每次登录最多自动播放一次，返回页面不重播。

持续运动只有实际轨道播放、必要进度与用户启动回放；不让卡片、标题、星点、数字同时循环呼吸。球体运动用渲染引擎时钟与采样插值，不能依赖 React 每帧 setState。

系统 prefers-reduced-motion 或应用“减少动态效果”启用时：跳过入场、关闭位移动画、相机立即定位或短淡入；保留用户明确启动的轨道/过境播放并可暂停。降低画质与减少动态效果是不同设置。

## 8. 键盘、焦点与可读性

- Tab 顺序按导航 → 查询/条件 → 主操作 → 结果 → 详情 → 时间控制；提供跳转主要内容入口。
- 地球作为独立可聚焦区域，提供“恢复视角”“缩放”“定位选中目标”的按钮；列表始终可替代点选。
- 不全局截获 Space、方向键和 Escape。时间条拥有焦点时才使用 Space 播放/暂停、方向键步进；输入框保持原行为。
- 对话框打开时地球键鼠交互停用，关闭后恢复。菜单和抽屉关闭后焦点回触发者。
- 焦点使用 2px 蓝色外环并留 2px 间距；固定顶栏、工具条不遮挡焦点。
- 状态变化使用节制的 live region；不逐秒播报全部位置数值。
- 不禁用浏览器缩放或粘贴密码；超长卫星名可换行，截断时提供键盘也能打开的完整名称。

## 10. 设计验收与交付顺序

优先实现：基础 Token → 应用壳与表单 → 探索目录/详情 → 地球与相机 → 时间/状态组件 → 观测规划 → 天气/大屏/管理。

每个页面验收：

- 默认、加载、空、失败、陈旧和无权限状态是否完整。
- 1440×900、1920×1080、2560×1440 与 200% 缩放是否可操作。
- 透明面板叠加白云、亮地表后是否仍清晰；控制边界和焦点可见。
- 快速选中、重复打开关闭、跨页返回时是否有错误残留或焦点丢失。
- 动画正常与减少动态效果模式均可用；全屏、鼠标与键盘均有退出路径。
- 每个实际展示的数据和状态是否对应后端语义，概念图内容没有作为假数据遗留。

本次交付为规范和静态参考，不宣称已通过浏览器、可访问性或帧率验收；这些验证在可运行原型阶段执行。

## 11. 设计依据记录

使用 ui-ux-pro-max 本地设计检索与桌面 Web 交互指南。两次系统级检索分别偏向营销页与拟物界面，与当前科学工作台不匹配，因此未将其布局/配色直接持久化；全局视觉以用户确认的 A 为准。键盘焦点、可见错误、拖动替代、对比度与减少动态效果采用其已核对的通用指南。
