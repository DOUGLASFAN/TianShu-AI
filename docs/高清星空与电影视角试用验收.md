# 高清星空与电影视角试用

2026-11-19｜根据用户对前版银河清晰度和真实感的反馈，复用现成专业资源进行试用。属于现有探索页增强，不启动后续开发阶段。

## 本轮结果

探索页左上“太空”中保留自由旋转的星空背景，并新增“电影视角 · 4K”。背景与电影采用不同的现成资源，不再用一张模糊全景冒充动画。

背景使用 NASA **Deep Star Maps 2020** 的 8192×4096 HDR EXR 原始数据，依据星表制作。离线转换为六张 2048px 无损 WebP，替换前版六张 1024px 天空盒；实际纹理总像素数提高四倍。运行时直接交给 Cesium 加载，没有运行时逐像素重投影，也没有随机绘制新的银河或恒星。原始 HDR 转为浏览器图像需要色调映射，当前显示不是保留半浮点动态范围的原始 EXR。

电影采用 NASA **Flying Through Galaxies** 的原始 3840×2160 MP4，约 141.8 MiB。本轮没有使用球幕预览作为矩形背景，而选择了适合普通屏幕的成品穿行动画。文件没有转码、降采样或重新绘制；浏览器实测能够解码、跳转和连续播放，两个时刻的帧指纹不同。

电影是独立播放器，不是将 Gaia Sky 桌面程序移植进网页，也不提供自由改变影片镜头的功能。星空背景本身保持静态；动态镜头与光变来自现成电影。没有把随机闪烁或自行生成的星云包装为“真实银河”。

## 交互与性能

- 电影弹窗支持原生播放／暂停／进度／全屏，保留原始资源入口与署名。
- 系统减少动态效果时不自动播放，用户仍可主动播放。
- 打开电影暂停后台 Cesium 绘制，减少解码与三维渲染争抢资源；关闭后恢复原视角与渲染状态，不替换轨道数据。
- Escape 或关闭按钮均可退出，滚动锁与焦点恢复；手机尺寸下保留完整关闭入口。
- 电影只在打开时加载元数据／按需读取视频，未打开不会预下载整部影片。所有运行素材在 D 盘项目内，无运行时外部视频依赖。

## 验证

使用 Edge、1920×1080 与 390×844、软件 WebGL。验证了六面实际贴图为 2048px、GPU 场景无错误、影片原生尺寸、减少动态效果偏好、两处跳转帧不同、连续播放推进、后台绘制暂停／恢复、Escape 和手机关闭、切页释放场景。详细结果以[浏览器记录](./evidence/hq-galaxy-browser-2026-11-19.json)为准。

构建：`npm.cmd --prefix frontend run build`。

复查：服务启动后在 `frontend` 执行 `node verify-hq-galaxy.mjs`。不改写数据库和真实故障演示状态。
