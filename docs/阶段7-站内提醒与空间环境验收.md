# 阶段 7：站内提醒与空间环境

交付范围：S07-01～S07-07。实际完成状态以[阶段验收清单](./阶段验收清单.md)为准；阶段 8 未启动。

## 使用入口

在观测规划保存计划时选择提前 5／10／30 分钟。服务运行期间，真实 UTC 时间到达阈值后产生站内通知；右上角铃铛显示未读数，点击进入通知中心，可按全部／未读查看、标为已读、全部已读并打开对应计划。取消或重算会撤销旧版本通知，其历史记录仍保留，并明确标记已撤销。计划详情中的“已生成通知”只代表通知已经持久化，不等于用户已经看到，也不承诺系统桌面、邮件或短信通知。

导航中的“空间环境”提供 Kp 观测、未来预测、近七天官方通报数量、24／72 小时观测趋势，以及单列的预测曲线。事件支持属性、类别、来源、最近 1／7／30 天和分页；打开详情后，关闭或浏览器返回保留原列表条件。详情保留发布时间、发生时间、采集时间、源站等级、原文、原始记录和来源链接。

## 提醒的时间与一致性

- 后台 worker 每秒检查真实系统时间；模拟回放的时间、倍速与跳转均不进入调度接口。四个并发调度者的真实 PostgreSQL 测试只生成一条通知。
- 调度先锁计划，再校验版本、取消状态、用户启用状态和提醒状态，最后在同一事务内写通知并将提醒改为 `sent`。唯一键为计划 ID／版本／阈值；事务回滚后可重试，不以 WS 成功发送作为持久化条件。
- 正常运行允许最多 60 秒的调度宽限，通知同时保存原计划阈值时间和实际生成时间；超出宽限或过境已经开始时标记 `missed`。页面不冒充“准时送达”。
- worker 重启的第一轮专门恢复：阈值已过的待处理提醒直接记为错过，不补发；未来阈值继续等待。数据库临时不可用时下一轮重试恢复，不因一次失败永久跳过。
- 取消和确认重算沿用计划行锁：旧待处理提醒撤销，旧通知记录标记撤销，未读徽标排除已撤销版本，新版本生成新的未来提醒。已读操作幂等且严格限制为当前用户。
- WS 沿用单次票据、会话有效性、序列号与心跳。通知变化最多两秒检查一次；重连读取持久化摘要，无需重放易重复的临时消息。连接中断时通知中心每 15 秒、徽标每 30 秒回查；更新不强制切页、弹窗或移动焦点。

## 天气来源与语义

| 来源 | 已接入的产品 | 呈现与验证边界 |
| --- | --- | --- |
| NOAA SWPC | 三小时 Kp 观测、Kp 预测、官方 alerts 通报 | 本机实际 HTTP 成功，原始响应、哈希、采集记录、解析结果和事件持久化 |
| GFZ | Kp nowcast 文本 | 本机实际 HTTP 成功，保留暂定／最终状态；仅提取 Kp，不使用黑子数等字段 |
| NASA DONKI | 耀斑、日冕物质抛射适配 | 适配与异常呈现已实现；本机来源仍不可达，没有冒充成功数据或填充示例事件。属于可选补充，当前实际事件链路使用 NOAA |

资料：[NOAA Kp 产品](https://www.spaceweather.gov/products/planetary-k-index)、[NOAA 产品目录](https://services.swpc.noaa.gov/products/)、[GFZ 数据说明](https://kp.gfz.de/en/data)、[DONKI API 说明](https://ccmc.gsfc.nasa.gov/DONKI/api/)。

每十分钟独立采集六项产品，来源间并行且与提醒调度分开。请求验证 TLS、限制响应大小和超时，不忽略证书错误；网络传输失败允许一次 curl 替代，HTTP 错误不无限重试。成功前完整解析，失败保留上次有效快照；单个来源失败不覆盖其他成功来源，全部来源失败时调度记录失败。历史中断采集标记 `WORKER_INTERRUPTED`。

原始响应位于项目 `.local/data/environment/`，数据库保存 SHA-256、原始路径、来源、采集记录、源数据时间和源站提供的发布时间。未提供的发布时间／发生时间保持为空；采集时间不冒充发布时间。读取原始文件需要登录且限制在专用目录。相同源事件标识去重，后续更正更新当前事件，旧原文仍可在采集快照中追溯。

Kp 仅接受有限的 0～9 数字，缺测 `-1` 不当成零。NOAA 观测、估计、预测保留原属性；位于未来的 estimated 时段按预测显示，避免把未来值画成观测。GFZ 暂定值不冒充最终值。官方等级只从源字段／通报原文读取，不根据 Kp 补造“官方 G 等级”。未知通报类型保持一般通报。

观测数据时间超过六小时、采集超过对应产品时限、或预测已无未来覆盖时标记过期；无有效值标记未知。观测优先使用有效 NOAA，失效时选择有效 GFZ；均过期时保留历史值并显示“状态未知”，不标为正常。官方通报不自动视作当前有效预警，详情对未给出有效期、过期和撤销分别提示。全球环境只用于一般影响解释，不能判断本地设备或某颗卫星已经故障。

GFZ Kp 采用 CC BY 4.0，署名 GFZ／Matzka et al. 2021，DOI `10.5880/Kp.0001`。保存的完整原始文本还包含 CC BY-NC 4.0 黑子数字段，原文件许可头保留，界面注明该区别，不将整份原文一概声称为单一许可。
