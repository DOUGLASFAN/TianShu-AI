## 公网首屏传输优化

- ECS 的 Nginx 已启用 HTTP/2、JavaScript 与 JSON 等格式的 gzip 和静态构建资源缓存。Cesium.js 的公网 gzip 响应为 1,778,726 字节，原始文件为 6,095,011 字节，传输体积下降约 71%。Nginx 配置检查及公网响应头检查通过。
- 公网完整下载 gzip 引擎实测 14.72 秒。全新 Edge 会话以 393 × 852 尺寸测试，从点击游客体验到三维场景首帧为 29.74 秒，确认引擎通过 HTTP/2 传输 1,778,726 字节。两次计时为不同的请求。
