## 已选择的具体方案

1. 延续 A 写实航天，采用既有蓝黑、青蓝操作和琥珀选中 Token。NASA 式空间层次 + KeepTrack 式功能关系 + Nullschool 式克制。
2. 主场景必须是 Cesium 实际渲染的 WGS84 地球。使用 Solar System Scope / INOVE 的 CC BY 4.0 地表、夜光和云层 8K 贴图，真实昼夜由模拟时间驱动。标明历史合成贴图，供应方未注明确切年份时说明未知，不冒充实时云图；不使用 AI 地球图片作为球面地理资源。
3. 主画面由顶栏、左目录、中间地球、右详情、底部统一时钟构成。地球在独立安全区域中居中，跟踪时目标不得落在侧栏后面。可切换纯净视图，让地球获得更大空间。
4. 首屏突出地球与少量有真实根数的代表卫星。全球目录仍完整分页，三维展示范围明确标注；不把万颗目录数量冒充当前绘制数量。全球海量点性能归阶段 4/9。
5. 选中后仅突出当前卫星、空间轨道与地面投影；图例区分两种线。普通卫星少标签，选中目标使用琥珀色；颜色不表达威胁等级。
6. 定位与持续跟踪为独立操作；新选星取消旧请求和相机飞行，只有最后对象生效。拖动解除跟踪并提示；全球视角恢复默认镜头，关注保留。
7. 列表/详情来自正式数据库接口，采样来自后端 SGP4。时间步进插值，样本区间以外不外推；更新失败显示暂停/范围结束，不能继续伪装实时。
8. 底部显示 UTC、当前时刻/暂停查看/时间推演、倍率、采样区间和状态。历史根数、采集时间、位置类型分别说明。连接正常不代表根数新鲜。
9. 动画主要用于相机过渡、面板切换与真实卫星运动。不开全屏阻塞入场；减少动态效果时关闭面板位移、相机立即定位。相机任务可以打断，不排队执行过期动作。
10. 加载、无结果、请求失败、陈旧根数、无法传播与无采样位置均有可见说明和恢复入口。只在实际写入成功后更新关注状态。

## 阶段 3 的视觉检查门槛

- 在 1440×900、1920×1080、2560×1440 浏览器实际观察：地球轮廓清晰，地表与大气层可辨，轨道细且可识别，侧栏不遮住选中目标，文本与按钮不裁切。
- 搜索 ISS → 查看真实详情 → 定位 → 跟踪 → 拖动退出 → 关注 → 全球视角完整操作，并保留实际截图与验证记录。
- 快速重选不显示旧详情/旧采样；切页后销毁 Cesium 与事件、定时器；减少动态效果、键盘操作和低高度布局分别检查。
- 浏览器软件 WebGL 截图用于功能和布局验证，不冒充用户 GPU 上的帧率验收。完整性能目标仍由阶段 9 实测。
