# 星枢 · 阶段 2 验收报告

验收日期：2026-11-12。结论：S02-01～S02-08 全部通过，本阶段完成。逐项状态以[阶段验收清单](./阶段验收清单.md)为准。

## 交付结果

正式工程采用 React、TypeScript、Vite、TanStack Query、Motion，以及 FastAPI、SQLAlchemy、Alembic、PostgreSQL 和 Redis。依赖锁文件、数据库迁移、独立采集入口、启动停止脚本、API 契约和部署说明已交付。前后端独立启动，通过自有 HTTP 接口通信。

实际数据库具有 10 张业务表、9 个外键和 15 个索引，已导入带来源时间的 16,899 颗真实卫星。卫星、分组、根数历史、采集记录、账户会话、私人关注和观测站均实际持久化。应用数据库角色不是超级用户。迁移可重复执行，`alembic check` 无待生成变更。

注册、登录、退出、Cookie 恢复、账户禁用、管理员保护及跨用户隔离已实现。密码使用 Argon2，JWT 固定算法、签发方、接收方及必要字段；数据库会话支持退出即时撤销。浏览器访问令牌仅留内存，恢复 Cookie 为 HttpOnly、SameSite Strict；本机 HTTP 使用非 Secure Cookie，HTTPS 部署需开启 Secure 配置。已提供后端登录限流与缓存故障时有界降级。

目录支持搜索、分组、分页、详情及来源时效；关注和站点写入真实数据库。管理员可查看用户、数据源和采集记录，并执行受保护的基础管理。采集先验证完整候选批次再事务替换，失败保留有效版本；缺少元数据不会抹掉已有归属和发射日期。该阶段手动与独立命令采集可用，定时调度和实时推送仍在后续阶段。

## 运行和边界

当前应用：[本地工作台](http://127.0.0.1:5174/)，接口文档：[OpenAPI 页面](http://127.0.0.1:8001/docs)。账户口令只保留在项目私有 `.local/config/demo-accounts.json`，不写入本文。

主要依赖和持久化数据位于项目 D 盘目录。PostgreSQL 使用 EDB 官方 Windows 二进制；Redis 使用 redis-windows 社区 Windows 构建，已核对发布资产摘要，不能称为 Redis 官方 Windows 发行版。PostgreSQL 下载文件已记录 SHA-256，但未取得独立发布方摘要交叉验证。

本机 Docker 不可用，因此采用项目内原生服务完成初始化、连接、健康与重启验收。初版 Compose、Dockerfile、Nginx 及容器初始化脚本已交付；仅解析检查 YAML，**容器构建和运行未验证**，最终部署验收仍保留在阶段 10。

当前界面是认证与目录工作台。A 方案正式三维首页、高清地球材质、完整轨道动画与持续跟踪尚未交付，不能用当前界面代替阶段 3 视觉验收。后续阶段的完整管理中心、预测、计划、通知、大屏与综合性能验收也未提前勾选。
